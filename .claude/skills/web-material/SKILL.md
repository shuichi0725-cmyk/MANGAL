# Web材料 (= トリガー「Web材料集めて [N]」「Web材料続けて」「Web材料判定して [N]」「Web材料止めて」「Web材料どう?」)

ユーザ発案(2026-10-29)「haikuがネットで集めた情報を入れる器を作ってほしい。いつ。どこで、情報をえたか。漫画ごとに情報を得るだけまず進めてみる」。

## これは何か
- 対象 = 巻数5以上・見える要素(隠し以外)3以下の頁。**巻数の多い順**(ユーザ指定。人気順ではない)。
- 道具 `scripts/_web-material.py` が `_element-harvest.py auto`(v0.6〜)を1作ずつ呼び、結果を器へ写す。
- 器 = `.cache/web-material/`(store/<stem>.json・work/=取った頁の全文・runs.jsonl)。★**ローカルだけ・git に入れない・D ドライブを使わない**(ユーザ裁定)。
- ★**集めるだけ**。要素・ジャンルを付けない。本番(manga.v2 / .preview-data / seed / 索引)に一切書かない。付与案(Sonnet)はユーザが言った時だけ別に。

## Haiku への命令の型 (= 2026-10-30 決定。命令文を変える時もこの型を守る)
1. Haiku は**選ぶだけ**: 開く頁の番号 / 採る段落の番号+役割(物語/作風/人物/主題/展開)+scope(全体/一編)/ 使わない理由(決まった選択肢)/ 同じ作品だと示す語句。文章は書かせない(本文は道具が原文を写す)。
2. 機械で確かめられることは聞かない(題・著者名・止め札・対象外サイト・重複・上限)。
3. Haiku の答えは道具が全部検算し、通らなければ理由つきで不採用(器に残る)。
4. 要素の判断は収集でさせない。
- ユーザが「〜をもっと探させて」「〜はいらない」と言ったら、`_element-harvest.py` の LOOK / QUERIES / judge_page の命令文に足し、VERSION を上げ、2〜3作で前後比較してから流す。

## 手順
- **「Web材料どう?」** = `python scripts/_web-material.py status` を打って、器の作品数・材料の字数・次の作品・最後の回を報告。
- **「Web材料集めて [N]」**(N 省略 = 20)=
  1. `status` で次の作品を確かめる。
  2. 1行予告(「N作 約{N×2.5}分・約${N×0.015}」)して、`python scripts/_web-material.py run --n N` を **run_in_background**。★Monitor で `✔|✘|失敗|終わり|Traceback|止め` だけを拾う(skill long-job-ops)。
  3. 終わったら結果だけ報告: 入れた/失敗の数・材料が薄い(1,500字未満)作品・失敗の理由。途中経過は報告しない。
- **「Web材料判定して [N]」**(N 省略 = 20)= 器の材料から**付与案**を作る(★案だけ。頁・seed に書かない。入れるのはユーザの Go の後で別に)。
  1. 1行予告(「N作 約{N}分・約${N×0.011}」)→ `python scripts/_web-material.py judge --n N` を run_in_background + Monitor(`✔|✖|終わり|Traceback`。節目だけ)。
  2. 道具は器に在り・材料が0字でなく・まだ案の無い作品を巻数順に取る。モデル = Haiku(2026-10-30 ユーザ裁定「Aでいく」)。案は器の `judges` に いつ・モデル・版 付きで残る。
  3. 終わったら: 案の数・失敗・費用・**見える要素が4語以上になる作品の数**・目立つ語(例えや宣伝文句から来た語が無いか、`work/<stem>/assign/assign-proposal.md` の根拠を数件抜き取って見る)を報告。
- **「Web材料続けて」** = 同じ(道具が器に在る作品を飛ばすので、続きから始まる)。
- **「Web材料止めて」** = CommandLine に `_web-material|_element-harvest` を含むプロセスを `taskkill /T /F` で全部止める(止め残すと2本並走する)。途中の作品は次回やり直し。
- 1作だけ集め直す = `run --stems <stem> --redo`(前の回は消えず、回ごとに残る)。中身を見る = `show <stem> --text`。

## 止まる時・気をつけること
- 道具は3作続けて失敗すると自分で止まる → 理由を見て報告(魚の失敗・Haiku の時間切れ・AniList など)。直さずに流し直さない。
- 頁の題が短い・一般語で別作品ばかり当たる作品は `data/element-harvest/search-titles.yml` に検索用の題を足す(出所を note に。頁は変えない)。例 = ゼロ。
- ファイル名と公開slugが違う260頁は今は対象外(道具が飛ばす)。
- 経緯・数字 = memory `long_series_web_harvest_trial`。
