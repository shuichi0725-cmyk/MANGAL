# 共有ISBN問題: 監査結果と修正計画 (2026-06-24)

## 発端
ヴァルキリープロファイルの巻数が壊れている（魔神ぐり子4巻/金田一5巻/祥寺5巻だが、固有巻は各1巻）。
原因＝アンソロジー寄稿者ページに**同一ISBNが重複計上**。

## 監査結果（本番 manga.v2 全量）
- 全ISBN: 248,931 / **共有ISBN（2ページ以上に出現）: 2,264** / **影響ページ: 849** / **クラスタ: 363**
- 種2 では共有ISBN = **0件**（各ISBNは1seriesのみ所属）。
  → ★**問題は promote が作っている**（種2は健全）。データ: `data/seeds/shared-isbn-audit.tsv`

## 根本原因
`_promote-bulk-v2.py` の `find_related_series_ids`（L1234〜）が同題/題断片の別series巻を
**各ページに混ぜ込み、正本1ページに集約しない**。種2の1ISBN→1seriesが、本番で1ISBN→N pageに増殖。
- merge条件: 同qid+題一致 / orphan題一致 / merge_sids。**orphan題一致が断片で誤接続**（"sai"等）。

## 2つの機構（修正が真逆）
| 型 | 例 | 実態 | 修正 |
|---|---|---|---|
| **A 分裂集約** | はにたろうです13ページ/日本の歴史9/惑星年代記7 | テーマ別題の巻が別ページ化＋全巻ISBN共有。**本来1作1ページ** | 正本1ページに**集約**、他はalias/301 |
| **B 誤接続分離** | 15歳/16歳キス/17歳/19歳/27歳/菜 が1ISBN共有 | 題断片"sai"で別作を誤merge | 誤ISBNを正ページに戻し**分離** |

## クラスタ分類（363）
- **A_split_series（集約すべき）: 170**
- **B_false_link（分離すべき）: 16**
- **C_mixed（個別判断）: 177**
- ★A内にも危険: doraemon版違い4ページ/dragon-quest別作3ページ等。**機械一括は禁物**。

## 修正計画（慎重・GO制・可逆・小バッチ）
### 原則
- **種2を権威**とする（各ISBN→1series→正本1ページ）。本番で1ISBNは**厳密に1ページ**に。
- **A=集約 / B=分離** を型判定してから適用。教育系・同一IP別作（DQ/ドラえもん）は**人手確認必須**。

### 段階
1. **根本: `find_related_series_ids` 是正**（再発防止）
   - 題断片merge廃止（完全題＋著者/qid一致のみ）→ Bの誤接続を封鎖
   - merge cluster を**正本1ページに集約**（merged sidは独立ページを作らない）→ Aの重複消滅
2. **型別検証**（363クラスタを A/B/C で台帳化、サンプル目視）
   - C_mixed 177 は per-case（版違い統合 vs 別作分離 vs 偽merge）
3. **再promote**で本番再生成 → 共有ISBN=0 を確認（監査再走）
4. **可逆**: 旧本番backup、クラスタ単位で before/after 記録、異常時revert

### 安全策
- A集約は「同一作の確証」（種2同一series由来 or 連番 or 著者一致）がある時のみ。なければC送り。
- B分離は誤ISBNを除くだけ（ページ構成は不変）＝低リスク先行可。
- 出荷前に「共有ISBN 0」をゲート条件化。

## 残（このdocで未確定）
- find_related_series_ids の正確な誤merge経路（断片一致 or qid空一致）の特定 → 是正実装
- C_mixed 177 の内訳精査（版違い/別作/偽merge）
