# 2026年 取り逃し調査（NDL NDC726.1 全件 vs 種2）2026-06-23

## 目的
2026-01〜06 に刊行された漫画のうち、種2(db-v2)に**取り込まれていない**ものを洗い出す。

## 方法
- NDL SRU で `ndc="726.1"`(漫画) × `from/until`(月) を全件 harvest。
- ★NDL SRU は **500件/クエリの取得窓 + 日付は月粒度** の制約 → 各月(~1,200件)を **publisher facet(161社)で細分**して全件取得。
- ISBN13 を種2 volumes.isbn13 と突合。
- データ: `data/seeds/ndl-2026-harvest.jsonl.gz`(全6,898件) / `data/seeds/ndl-2026-gap.tsv`(取り逃し2,319件)。

## 結果

- **取り逃し 2,319件**。うち 88%(2,036件) が 4-6月 = 種2の cm101 取込が **3月頃で停止**した「崖」。
- 取り逃し 出版社TOP: 講談社317 / KADOKAWA281 / 小学館140 / 集英社139 / 秋田121 / スクエニ110。
- 1-3月の残10%前後は版バリアント(完全版/文庫等)や種2 clustering差。

## 完全性の限界（正直な記録）
- NDL自体が登録遅延 → 直近(6月)は NDL 側も undercount(530は月途中)。実刊行はもっと多い。
- harvest は publishers.yml 161社 facet 依存 → 未収載の零細出版社(~2%)は取りこぼし。
- Rakuten 併用案: gap 2,319件を ISBN で楽天 enrich(書影/在庫/アフィリンク)→ 種4取込準備。未実施。
