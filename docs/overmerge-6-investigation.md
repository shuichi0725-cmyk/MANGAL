# 過剰統合疑い 6クラスタ 深掘り調査 (調査・提案のみ / 適用なし)

調査日: 2026-06-26
手法: 各 `data/manga.v2/{slug}.yml` のボリューム単位 ISBN を抽出 → 2ページ跨ぎの**共有 ISBN** を特定 →
`.cache/db-v2.sqlite` で `volumes.isbn13 → edition → series → series_authors` を辿り、**各共有 ISBN の真の所属シリーズ/著者**を確定。
大原則: 確証なき統合・分割は禁止 ([[feedback_dont_repeat_regrouping_error]])。実データで裏付けたものだけ提案。迷ったら D。

分類: **A_過剰統合** / **B_別作誤ISBN** / **C_著者表記ミス(=実は同作)** / **D_判断不能**

### ④ 修正案
- `kibun-wa-mou-sensou-2002` (藤原カムイ版) から #1 `9784047133877` を**除去**(これは大友版 vol1)。
- 藤原版の正しい vol1 ISBN を別ソース(NDL/楽天)で確定し補完するまでは、藤原版は #2 `9784047134942` のみ、または「vol1 ISBN要補完」とマーク。
- 大友版 `kibun-wa-mou-sensou` は `9784047133877` を保持(正)。#2(ISBN無/1982)は大友の元版で別途精査。

### ⑤ 確信度: **高** (共有ISBNが大友sidに一意所属、藤原は別sid。実データ確証あり)

- ★安全策: まず「稲垣版ISBNの誤搭載除去」のみ確定(高確信)、MEIMU版の再割当ては別ステップ。

## クラスタ3: 魔法科高校の劣等生 (蒼和伸版 ⇔ きたうみつな2012版)

### ① 現状
| slug | 著者 | 巻数 |
|---|---|---|
| `mahouka-koukou-no-rettousei` | 柚木N', 蒼和伸 (原作 佐島勤) | 8 |
| `mahouka-koukou-no-rettousei-2012` | きたうみつな (原作 林ふみの/チョコカレー/佐島勤) | 8 |

共有 ISBN = **0件**

### ② 種2照合
両ページとも**内部に複数sidが混在**するが、**ページ間で共有するISBNは無い**。
- `-rettousei` (蒼和伸): スティープルチェース編/よんこま編(sid119560) + #8 が別sid166043。
- `-2012` (きたうみつな): sid3501 + 来訪者編(sid166045) + #8 が竹田羽角(sid119561)。
→ 各ページ内で**別アークの巻が混ざっている**(よんこま編/来訪者編/師族会議編 等、別コミカライズが1ページに同居)。

### ③ 分類: **D_判断不能** (ページ間過剰統合では**ない**。スキャン誤検出。ただし各ページ内に別作混在の別問題あり)
2ページ間に共有ISBNが無いため「keepが別ページの巻を取り込んだ過剰統合」には該当しない。
スキャンは同題+原作者(佐島勤)共有で誤フラグした可能性が高い。

### ④ 修正案
- ページ**間**の統合・分割は不要(本タスクの対象外として保留)。
- 別途の課題として: 各ページ内に「よんこま編 / 来訪者編 / 師族会議編 / 四葉継承編 / 孤立編 / ダブルセブン編」など
  別コミカライズ(別作画者: マジコ!/竹田羽角 等)が混在 → これは**ページ内の作品分割**問題で、本クラスタ調査の範囲外。要 別タスク化。

### ⑤ 確信度: 「ページ間過剰統合ではない」= **高** / ページ内分割の是非 = 要別調査

### ⑤ 確信度: 「現ページのISBNが別翻案所属」= **高** / 各ページの正しい再構成(特に松田版の正ISBN) = **中**(外部確証要)
