サンプル値について
  • 主要 table (= series / editions / volumes / mangaka / series_authors / publishers / magazines) は 「ONE PIECE」 系列の実 data を使用 (= 把握しやすさのため)。 他 table は最初の 1 row。
  • 「充足率」 = その column が NULL でも空文字でもない row の割合 (= data の埋まり具合)。
  • 「制約」 PK = 主キー、 ○ = NOT NULL。

パート 2: 種3 = AI 補完 yaml (= data/seeds/series-supplement-v2.yml)

種2 に 無い 「主観的 / curated data」 を AI (= Claude Opus 4.7) で 1 件ずつ補完し yaml に蓄積。 76,435 entries (= 種2 series の subset)。 promote-bulk 起動時に 種2 + 種3 を merge して 最終 data/manga/<slug>/index.yml を生成。

種3 の キー体系
  • 各 entry は key field で 種2 の series 1 件と紐づく。
  • key 形式: qid:Q…|name:<タイトル> または name:<作者>|name:<タイトル> (= qid 無し時)
  • fill 漏れた entry は yaml に 存在しない or field が空 → promote-bulk で fallback (= TODO_genre / 空文字 / null) 化。
