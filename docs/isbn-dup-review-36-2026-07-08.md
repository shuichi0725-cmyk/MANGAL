# ISBNダブリREVIEW 36件 調査レポート (2026-07-08・調査のみ/変更なし)

著者不一致で保留していた36件を TinyFish Search + 出版社 + NDL で分類。**変更なし**。

## ★方針(2026-07-08 ユーザ確定)
「アンソロだから排除」は誤り。**纏められる(1シリーズに統合できる)アンソロは掲載してよい**。排除は「纏められないもの」と「雑誌(定期刊行=号数)」のみ。→ 下記A節を再分類:

## A. アンソロジー(新方針で再分類)
- **X-MEN ×3** (竹書房) = 「竹書房バンブー X-MEN 全13冊」寄稿13作家。★**纏められる(全13巻の1シリーズ) → KEEP(統合)**。3頁を1頁に。※アメコミ題材だが日本で出版された日本人作家の漫画=掲載scope内。
- **テイルズオブエターニア プレミアムストーリーズ** (square-enix・全6巻) = 著者「アンソロジー」。★**纏められる(全6巻) → KEEP(統合)**。
- **コミックチューリップ ×3** (ピラミッド社) = ★**雑誌疑い→排除候補**。Wikipedia「かつて刊行された日本の漫画雑誌一覧」に登場・ピラミッド社レディコミ・3別作家同題。雑誌なら纏められても排除(要最終確認)。

## B. アンソロ series(新方針=纏められれば KEEP)
- **艦これ4コマ** (桃井涼太) = 単行本series「吹雪、がんばります!」。纏められる → KEEP。雑誌でなく単行本アンソロ。
- **NHKその時歴史が動いた コミック版** (集英社・編ごと別作家) = 全N巻の教育コミカライズseries。纏められる → KEEP(統合)。※雑誌でない。

## C. 同一作の作画交代 → 統合候補
- **名探偵コナン 特別編** = meitantei-conan-2005(阿部ゆたか) と -tokubetsuhen-2016(窪田一裕/太田勝) は**同一シリーズの作画交代**(青山剛昌原作・特別編は作画ローテ)。→ 1頁に統合が正。

## D. 同著者・別世代/別作 → 維持(統合しない)
- **デュエル・マスターズ 無印(16巻) × 2017(12巻)** = 松本しげのぶ同一だが世代別シリーズ(無印コロコロ1999〜 vs 2017)。別作=維持。※ローマ字題「DUEL MASTERS」は日本語化候補。
- **新上ってなンボ(22) × 新々上ってなンボ(5)** = 叶精作の別作(新/新々)。維持。

## E. 別コミカライズ(homonym・別作) → 維持
- **ファイアーエムブレム 1993**(島田ひろかず/scola) = FEの一コミカライズ。別作画版と別作 → 維持。
- **リング 1996**(永井幸二郎/講談社) = 鈴木光司原作の一コミカライズ。稲垣版とは別 → 維持。
- **スターオーシャン セカンドストーリー**(天麻灯/2巻) = 本編コミカライズ(ガンガン全7巻)とは別枠の疑い。要per-case確認。
- **破妖の剣**(厦門潤/集英社・5巻) = 前田珠子原作のコミカライズ。ISBNダブリの相方と別 → 維持見込み。

## F. 教育系(ユーザ方針=触らない)
- **日本の歴史** nihonnorekishi(児玉幸多88巻) / nippon-no-rekishi-2007-2(井上大助28巻) = 集英社学習まんが年代版。同名多数で危険。保留。

## G. 単独/dedup済canonical(この36では概ね正常・別件で個別課題あり)
- ウルトラセブン(一峰大二)/かりあげクン/おるちゅばんエビちゅ/海街diary/義風堂々/坊っちゃんの時代/霊験お初捕物控/チャレンジャーズ/アンネームドメモリー/ねこようかい/シリーズあたりまえのぜひたく/異世界に来たみたいだけど/final-fantasy-lost-stranger/妖精国の騎士Ballad(継ぐ視) 等 = dedup後の生き残り or 単独作。この36の文脈では基本正常。幽霊巻/ローマ字題等は前レポート(preview-audit-2026-07-08.md)参照。
