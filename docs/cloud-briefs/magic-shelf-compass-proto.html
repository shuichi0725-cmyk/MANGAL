羅針盤の試作 — 背景と選んだときの動き

画面は実際に触れます。 すぐ上の「背景」「動き」のボタンで切り替えられます。 周りの本に触れると糸が光って選ばれ、もう一度触れるか下の「〜の糸で進む」で、その本が新しい中心になります。 上の旅路の本に触れると、そこまで戻ります。

データは本番索引から計算した実物(約束のネバーランドから2歩分)。 下の「広げる ▸」のチップ(作者・雑誌・年・要素ごと)に触れると、その糸の本が最大24冊まで広がります。 広げた本のうち見本に含めていない先へは進めません。

網点の出方(背景が「書影・網点」の時)

  1. 触れる: その本の糸が糸の色で光って流れ、ほかの本は沈む。 下のシートがその本の紹介と「〈種類〉の糸で進む」に変わる。
  2. もう一度触れる/進む: 選んだ動きで移動。 前の中心は、来た方向の反対側に灰色の「来た道」として残る。
  3. 上の色チップ: 糸の種類を切ると、その方角の本が消える。
  4. 旅路の本: 触れるとそこまで戻る。
