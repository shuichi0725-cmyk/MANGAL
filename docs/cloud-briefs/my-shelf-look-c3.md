# 依頼書: マイ本棚の見た目 = C3「黒い棚+真鍮」

2026-09-28 ユーザ裁定。 [my-shelf.md](my-shelf.md) で作った本棚(`/shelf`)の**見た目だけ**を作り直す。
保存形式・棚URL・slug解決・作品頁の「しまう」ボタン・プレビュー専用の仕組みは**変えない**。

## 1行目 = 画面が何に変わるか

**`/shelf` が「黒く塗った展示棚」になる。 上に真鍮の銘板(集計3つ)、その下にタブ(もってる/ほしい/気になる)、
棚の中は1作品=1段: 左に1巻の書影を正面向きで1枚、右に題名・所持状況・巻の番号タイル(10巻で1行)。 段の下に棚板。**

今の「棚ごとに書影を横一列スクロール」は廃止。

## 決まっていること(ユーザ裁定・変えない)

- 形 = 「収集帳」の骨格(集計 → タブ → 作品ごとの行) + 棚らしさ(棚の枠・段・棚板・銘板)。 番号は全巻タイルで読める(案1系)。
- **書影は各作品の1巻を1枚だけ**。 背表紙として同じ書影を何度も並べる表現は使わない(ユーザ「くどい」)。
- 配色は C3 固定(下の色表)。 サイトの明/暗テーマに関係なく、この棚は常にこの配色(展示ケースの世界)。

## 画面の構成(上から)

1. **銘板**(真鍮): 3つの数字 = `もってる冊数`(もってる棚の owned 合計)/ `出ている続きの巻`(owned < 既刊 の差の合計)/ `全巻そろった作品`(完結かつ owned >= 既刊)。
2. **タブ**: `もってる N` / `ほしい N` / `気になる N`。 選んだ棚だけを下に出す(今は3段を縦に全部出している)。 選択は per-viewer の便利機能として保存してよい。
3. **棚**(黒い枠)の中に、作品ごとの**段**:
   - 左: 1巻の書影 44×64px(無ければ今の「背に題名」代替表示を流用)
   - 右上: 題名(太字)/ 所持状況1行(今の文言ロジックをそのまま。 続きが出ている時は強調色)
   - 右下: **番号タイル**(もってるの時だけ。 下記)
   - 段の下に棚板(9px)
4. 段に触れると作品頁へ。 長押し/「⋯」のメニュー(棚移動・巻数変更・取り出し)は今のまま。
5. 頁下の「棚をよそへ持っていく」(棚URL)は今のまま(色だけ棚に合わせる)。

### 番号タイル(もってるの段だけ)

- 1行 = 10巻の格子(`grid-template-columns: repeat(10, 1fr)`)。 **11・21・31…巻が必ず左端にそろう**。
- 1巻は書影が表すので、タイルの1番目は細枠だけの「1」(薄い)。 2巻から番号入り。
- 所持(n <= owned) = 真鍮の塗りタイル+濃い文字。 未所持(owned < n <= 既刊) = 透明+サンゴ色の枠と文字。
- **40巻を超える作品は畳む**: 所持の前半を1本の帯「2〜130巻 所持(129冊)」にまとめ、最後に持っている巻を含む10巻区切りの頭から個別タイル。
  例: 160巻中140巻所持 → 帯「2〜130巻」+ 131〜160 のタイル。
- 既刊が分からない作品(索引に巻数なし)はタイルを出さず、所持状況の1行だけ。

### ほしい / 気になる の段

- タイルは出さない。 代わりに `全N巻・完結/連載中` と **キャッチ**(`useMangaIndex({ withCatch: true })`、2行で切る)。
