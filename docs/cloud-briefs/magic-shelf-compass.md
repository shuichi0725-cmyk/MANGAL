## 1行目 = 画面が何に変わるか

**`/lab/magic-shelf` を開くと、サイトの器(ヘッダー・ナビ・一覧)が消えて全画面が1枚の「羅針盤」になる。
中央に1冊、周りにつながる約7冊が色の糸で結ばれ(北=作者 金・東=同じ雑誌 緑・南=同じ年に開始 紫・西=要素 青)、

辿った道は上の帯に横へ伸びていく。**

### 旅の始まり

- 最初の中央 = URL の `?from=<slug>` があればその作品、無ければ先頭100件(人気上位・すぐ届く)からランダムに1冊。
- 先頭100件の時点で中央の本と背景は出す。 周りの本は全件が届いてから(それまで糸の位置に淡い点滅の枠を出し「星図を描いています…」)。

### つながりの計算(試作と同じ規則)

逆引き表: 作者名(`authors` の名前部分)/ `magazine` / `year_started` / `themes`(要素)→ 作品。 対象は **書影(`cover`)とキャッチ(`catch`)がある作品だけ**。

**周りの本**(中央ごとに最大7冊)。 1冊は最初に当てはまった種類1つにだけ入る(作者 > 同じ雑誌 > 同じ年 > 要素)。
| 種類 | 条件 | 上限 | 方角 |
|---|---|---|---|
| 作者 | 作者名が1人でも重なる | 1(2冊目を出すなら -70°) | 北(-90°) |
| 同じ雑誌 | `magazine` 一致 かつ 共通の要素 >= 2 | 2 | 東(-20°, 20°) |
| 同じ年 | `year_started` 一致 かつ 共通の要素 >= 2 | 2 | 南(70°, 110°) |
| 要素 | 共通の要素 >= 3 かつ `popularity` > 3000 | 2 | 西(160°, 200°) |
並び順 = 共通の要素の数(多い順)→ `popularity`(多い順)。 ラベル = 作者「作者 ○○」/ 雑誌 = 雑誌名(`data/magazines.yml` の name)/ 年「2016年に開始」/ 要素 = 共通の要素を2つ「陰謀・政治」。

**糸を広げる**(下の「広げる ▸」チップ)。 中央ごとに次の単位を出す(各最大24冊・並び順は同じ):
作者(作者名ごと・全作品)/ 同じ雑誌(共通の要素 >= 1)/ 同じ年(共通の要素 >= 1)/ 要素(中央の要素のうち作品数の多い順に4つ・その要素を持つ作品)。

## 画面(スマホ 360px 基準・試作の寸法)

上から:
1. **糸の色チップ列**(全幅・高さ44): 作者/同じ雑誌/同じ年/要素(押すとその種類の糸と本が消える・もう一度で戻る)+右端「旅を保存」(今回は見た目だけ・押すと「準備中」)。
2. **旅路**(全幅・高さ56・チップ列のすぐ下): 辿った本の書影(28×39)を左から並べ、間を「その一歩で使った糸の色」の線でつなぐ。 最後に点線+「?」。
   長くなったら横スクロール・最新が右端(自動で右端へ)。 書影に触れるとその地点まで戻る。
3. **羅針盤**(残り全部): 中央の本 76×106(白い縁と淡い光)・周りの本 48×67・下にラベル(糸の色)。 楕円 rx=118 / ry=150 に配置。
4. **「広げる ▸」チップ列**(全幅・シートのすぐ上・横スクロール): 単位ごとに「週刊少年ジャンプ 24」のように冊数つき・糸の色。
5. **シート**(全幅・下・高さ96・明るい地): 書影+題名+1行の説明(糸の種類 — 理由)+キャッチ2行+進むボタン「〈同じ雑誌〉の糸で進む →」(ボタンの地が糸の色)。
   何も選んでいない時は中央の本の紹介と「周りの本に触れるか、下の『広げる』から糸を選ぶ」。

## 動き

- **選ぶ(2段階)**: 周りの本に1回触れる → その本が少し浮いて糸の色の光、その糸だけ太く・流れる破線、ほかの本は沈む(暗く・彩度を落とす)、シートがその本に変わる。
  同じ本にもう一度触れる/シートのボタン → 進む。 中央の本に触れる → 選択を外す。
- **進む = 糸を手繰る**: 画面(本と糸・背景ごと)が糸に沿って 0.75秒ですべり、選んだ本が中央へ。 ほかの本は消え、新しい周りの本が現れて糸が中央から伸びる(0.6秒)。
  前の中央は「来た方向の反対側」に**灰色・点線の糸・「← 来た道」**として残る(触れると1歩戻る)。 旅路に1冊増える。
- **糸を広げる(3段階)**: 「広げる ▸」のチップ → 周りの7冊が消え、その単位の本(最大24冊)が中央から飛び出して並ぶ → 触れて選ぶ → もう一度で進む。
  「✕ 閉じる」か同じチップでいつもの7冊へ戻る。 広げている時、中央の本は 60×84 に縮む。
- **広げ方(ユーザが選べる)**: 広げた画面の隅に4つの切替(アイコン+短い名前)。
  | 広げ方 | 配置 |
  |---|---|
  | 方角に扇 | 糸の方角に 140° の扇・3列(5/8/11冊)・内側ほど近い本で大きい(34×48 / 30×42 / 26×36) |
  | 同心円 | 全周に3重の輪(6/9/9冊)・内側ほど近い |
  | 年表 | 横軸=`year_started`(左が古い)・同じ列は下から積む(下ほど近い・1列7冊まで)・中央の本は上へ移りその年の位置に点線 |
  | 星屑 | 単位ごとに決まった種の乱数で散らす(毎回同じ)・重ならない・近い本ほど内側で大きい |
  - **初期値は糸の種類で決める**: 作者=年表 / 同じ雑誌=年表 / 同じ年=同心円 / 要素=方角に扇。
  - ★**同じ年の糸では「年表」を選べなくする**(全部同じ年で1列に潰れ7冊しか出ない=試作で実際に起きた)。
  - 選んだ広げ方は糸の種類ごとに端末へ覚える(次から既定)。 保存は try/catch・読むのは水和後。

## 背景 = 書影の網点(★作り方に注意)

- 中央の本の書影を画面いっぱいに敷き、**点(網点)の形でくり抜いて**見せる。 点の間隔 6px・半径 2.35px。 明るさ 0.82・彩度 1.25 ほど。 四隅は暗く落とす(ビネット)。
- 中央の本が変わると、**前の本の点がしぼみ、次の本の点がふくらんで1点ずつ入れ替わる**。 全体 約1秒・1点は全体の32%の時間で入れ替わる(なめらかな加減速)。
- ★**点の色を画素から読んではいけない**: 楽天の書影サーバーは別ドメインからの読み取りを許していない(2026-09-29 実測: `Access-Control-Allow-Origin` 無し)ので
  `getImageData` は使えない(試作は埋め込み画像なので動いていただけ)。
  → **重ね合わせで作る**: 画面外の canvas に書影を描く → 同じ canvas に「その瞬間の半径の円の集まり」を1本の path で描き
  `globalCompositeOperation = "destination-in"` で書影を点の形にくり抜く → 旧・新の2枚を表の canvas に重ねる。
  (読み取りをしないので、別ドメイン画像で canvas が汚染されても描画はできる。) 明るさ・彩度は canvas 要素の CSS `filter` で。
- **出方は切り替わるたびにランダム**(同じ出方を2回続けない)。 選ばれた出方の名前を画面上部に1.3秒だけ小さく出す(試作どおり)。
  各点の「入れ替わり始める順番」v(0〜1)= 次の式(中心 = 羅針盤の中央、d = 中心からの距離/最大距離、a = 真上を0として時計回りの角度/360°、i,j = 点の列・行、W,H = 列数・行数):
  | 出方 | v |
  |---|---|
  | 内周から | d |
  | 外周から | 1 − d |
  | 外周から回る | ((1 − d)×3 + a) / 4 |
  | 内周から回る | (d×3 + a) / 4 |
  | ばらばら | 乱数 |
  | 時計回り | a |
  | 反時計回り | 1 − a(a=0 は 0) |
  | 左上から | (i/W + j/H) / 2 |
  | 右上から | ((W−1−i)/W + j/H) / 2 |
  | 左下から | (i/W + (H−1−j)/H) / 2 |
  | 右下から | ((W−1−i)/W + (H−1−j)/H) / 2 |
  点 k の進み q = clamp((全体の進み − v×0.68) / 0.32)、smoothstep。 旧の点の半径 = R×(1−q)、新の点の半径 = R×q。
- 背景も「糸を手繰る」ですべる時は同じ向きに少し(本の 0.6倍)流れる。
- `prefers-reduced-motion` の時は動きを全部止める(すべりも網点の入れ替えも即時)。

## 守ること

- ★本番に出さない: `page.preview.tsx` のまま。 共通シェル(ヘッダー・ナビ)には触らない(この頁は器の外に全画面で出す)。
- ★CSS は頁専用ファイルに書く(Tailwind の新しいクラスを足さない=本番の共通CSSを1バイトも変えない。 `app/shelf/my-shelf.css` と同じ流儀)。
- 描画中に保存を読まない(水和後)。 価格は書かない。
- つながりの計算・広げる単位・4つの広げ方の座標・網点の出方の順番 v は**純関数**にしてテストを付ける(種類の優先順位・上限・同じ年で年表を選べない・11の出方の v が 0〜1 に収まる、など)。
- 1冊の中央につき計算は1回(周りと広げる単位をまとめて)。 7万件の走査を毎タップでやり直さない(逆引き表は索引が届いた時に1回作る)。
- `npx tsc --noEmit` と既存テスト green。 `MANGAL_DATA_DIR=.preview-data` のビルドで頁が出て、通常ビルドでは出ないこと。
- push は最後に1回(`claude/manga-database-affiliate-3x0ms`)。
