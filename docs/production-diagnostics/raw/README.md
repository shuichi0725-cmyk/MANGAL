# 調査の生データ (= 再取得が高価なのでgitに焼く)

★ここに置く基準 = **外部ライブ照会に時間を要した結果**。 `.cache/` は gitignore なので
消えると数時間の再照会になる(2026-07-28 に実際に危うくなった)。 集計TSVだけでなく**生データ**を残す。

| ファイル | 中身 | 取得コスト |
|---|---|---|
| `recent-ongoing-volumes.jsonl.gz` | 連載中×最終巻2024年以降 **7,719作**の楽天照合(末尾続刊TRAIL/途中欠番GAP) | 楽天ライブ 7,719件 ≒ **2.8時間** |
| `recent-ongoing-input.json.gz` | 上の入力(slug/title/authors/所持巻リスト) | — |
| `ongoing-cont-rakuten.jsonl.gz` | 連載中×最終巻2023年以前 **3,367作**の楽天照合 | 楽天ライブ 3,367件+再照会 ≒ **1.5時間** |
| `ongoing-stale-input.json.gz` | 上の入力 | — |

集計は `../recent-ongoing-volumes.tsv` / `../ongoing-continuation-rakuten.tsv`。
再集計は `python scripts/_report-recent-ongoing.py`(jsonlを .cache に戻してから)。

★誤検出ゲートの履歴(この2調査で確立・検出器に実装済み):
 ①`size=コミック` 必須 = ラノベ原作の**小説巻**を続刊と誤認しない(痛いのは嫌なので防御力に極振り: 漫画8 vs 小説18)
 ②`same_series` = 題の包含だけでは**続編シリーズ**を拾う(白竜21 vs 白竜HADOU 49)
 ③セット/合本/分冊版/話売り 除外
 ④著者一致ゲート
 ⑤★**種2・種4・本番のISBN三点照合を必ず通す**。 番号ベース検出は「本番の別頁に在る巻」を
   取りこぼしと誤判定する(仕掛人藤枝梅安・左ききのエレンで実証。 種4に入れると二重登録)。

★NDL版(`ongoing-cont-ndl`)は **採用しない**。 修正前コードで走った上、NDLは電子の話売り/分冊版を
収載するため巻数体系が別(チート魔術74巻等)。 かつ MADB(種1)の提供元がNDL=同一源で追加価値が小さい。
