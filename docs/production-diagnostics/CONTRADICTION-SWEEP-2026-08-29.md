## 確実に直すべきもの (優先順)

### 1. 銀牙伝説Weed 43-60巻 = 壊れたISBN 18巻 【確実】
43〜59巻の**17巻が同一の壊れたISBN `9789784537100` を共有**、60巻は `9789784537124`。
正体は `"978" + "9784537100"` の**二重接頭辞**(ISBN-10→13変換を二度適用した痕跡)。
チェックディジットは**通ってしまう**ので検算だけでは止まらない。全18巻とも書影null。

- 発生源 = `data/seeds/edition-canonical/ginga-densetsu-weed.yml` L133-184(source欄「Wiki蒸留(手動)」)。
  ★canonicalは後勝ちなので種4/edition-overridesで直しても無効。
- 真ISBNの帯は分かっている(43-59=978-4-537-10xxx-x / 60=978-4-537-12xxx-x)が**下4桁は外部照会が要る**。
- ★**自動適用禁止**。値が判明するまで壊れた値を残すか空にするかも人手裁定([[never_delete_because_broken]])。

**恒久策(本命)**: `_audit-isbn-syntax.py` の judge() は副作用なしの純関数。
`_reflect-targeted.py` の検証ゲートから import して「壊れたISBNを含むseedはpush前に停止」を入れられる。
★DOUBLE_PREFIX は検算を通過するので、**構造判定(978/979の直後に9784が来る)を必ず一緒に**入れること。

### 2. 同一頁内のISBN重複 101群 / 56頁 【精度100%】
1つの頁の中で同じISBNが2度使われている = 定義上すべて誤り。反証者が19件検査して**偽陽性0**。

- **NUM_INFLATION 24群/24頁** = 同一版の別の巻に同じISBN = **巻数の水増し**。
  ★既存検出器のどれにも出ていない完全な新規(deluxe監査は版が2つ無いと動かず、cover-dup は書影nullで沈黙)。
  巻抜け仮想・巻番号監査にも偽の穴を作るので**最優先**。
- **EDITION_DOUBLE 77群** = 別の版に同じISBN = 版の二重計上。うち56群は `_audit-deluxe-label-split.py` と重なる。
- 刷タブが本体volumesを写す MIRROR 475群は**正当**として既定で非出力(機械的に分離済)。

### 3. 頁をまたぐISBN重複 325 ISBN / 182頁 【精度100%】
反証者が14件検査して**偽陽性0**。

- **GRAFT_ISOLATED 36組** = 衛星頁(≤2冊)の全部が相手の大きな頁に含まれる。
  ★是正の向きが機械的に確定するので **`page-dedup.yml` へ自動適用してよい唯一の層**。
- PAGE_DUP 26組(頁丸ごと二重) / WRONG_ISBN_FILL 5(別作品ISBNの混入) は per-case。

### 4. 発売日の小さな逆行 443版 【精度9/11】
既存 `_audit-vol-date-regression.py` は**5年以上**だけを見ていた。その下の層が未検査だった。

- **SINGLE × T1(1年以上) 98版**が最も費用対効果が高い(1巻だけ日付が飛ぶ型)。
  楽天キャッシュにISBNが在れば `salesDate` で一発確定できる。
- 実測で外部確証つきの本物6件を確認(境界線上の日本の刊行=DBと楽天が実際に食い違う)。

### 5. page-meta の dummy2000 313頁 + page_gen_year 222頁 = 535頁 【反証不能=確実】
`year_started` が promote の fallback 既定値 2000 のまま固着している型。
**是正は値を捏造せず「seedのysを消して promote に巻から再導出させる」だけでよい。**
対象slugを列挙して targeted反映で回す(全DB一括書き換えはしない)。

## 使えないと分かったもの (反証の成果)

- **`date-bulk-registered` の actionable 段は反証 0/6**。「レーベルが本当に同日出荷した」が普通に起きるため。
  BROKEN 16塊だけ人手で見て、残りは月次で新規増加分だけ見る運用にする。
- **`date-outlier` は 2/8**。実是正対象は150行のみ、残2,372行は情報段。**触ってはいけない**。
  BULKクラスは兄弟の `date-bulk-registered` が上位互換なので、そちらを正本にする。
- **`isbn-band-outlier` の F参考レーン(1,286巻)は 6/6 偽陽性**。版元移管で説明がつく。散発40巻だけ見る。
- **`isbn-seq-vs-volume` は 2,626 のうち A層96行**(うち特装signal付き75行は実測10/10真)。
  B/C/Dの2,530行は払い出しノイズと帯切替で、監視用に置くだけ。
- `date-crosspage-conflict` は「矛盾の存在」は10/10確実だが、**7/10は日付でなく重複版・重複頁の症状**。
  出力単位をISBN行から版ペアに変えると 160行 → 85単位。芯は NUM_CONFLICT SAME_EDITION 24 + DATE_CONFLICT_YEAR 20 の44行。
