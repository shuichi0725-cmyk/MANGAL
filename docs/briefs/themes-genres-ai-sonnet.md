# 指示書: 要素・ジャンルを厚くする(③④)— Sonnet 5.5 担当

作成 2026-10-02 Opus。道具 = `scripts/_themes-genres-ai.py`(冒頭の説明も読むこと)。
分担 = **あなた(Sonnet)が判定を書く → Opus が点検 → 本番**。あなたの仕事は「材料を読んで、閉じた語彙から選び、根拠の語句を材料から写す」ことだけ。材料の用意・機械検査・書き込みは道具がやる。

## 2つの作業

| 作業 | 対象 | 足すもの | 書込先(道具が書く) |
|---|---|---|---|
| ③ `themes` | 要素が0個の頁 27,817 | 要素(和名) 0〜3個 | tags-enrich-2425.json |
| ④ `genres` | ジャンルが汎用だけ(ドラマ/コメディ/恋愛/日常/アクション/other)の頁 15,167 | 具体ジャンル 0〜3個 | genre-append.yml(既存は消さない・出所つき) |

対象と材料は作成済み: `.cache/tg-ai/themes-targets.jsonl` / `genres-targets.jsonl`(作り直しは `prep`。勝手に作り直さない=idがずれる)。

## 進め方(1回分)

1. `python scripts/_themes-genres-ai.py show <task> <開始id> 50` で50頁ずつ読む。
2. 判定を `.cache/tg-ai/<task>-ans/<開始idを4桁>.jsonl` に書く(例 `themes-ans/0000.jsonl` に id 0〜199)。**1頁1行、付けない頁も必ず1行**:
   ```
   {"id": 12, "add": ["ヤクザ"], "basis": {"ヤクザ": "やくざの構成員として生きる"}}
   {"id": 13, "add": [], "skip": "材料不足"}
   ```
   skip の理由は次のどれか: `材料不足` / `該当なし` / `混入疑い`(材料が題と別作品に見える) / `範囲外`(画集・資料本・アンソロジー等)
3. 200頁ごとに `python scripts/_themes-genres-ai.py check <task>` を打ち、NG を直す(NGは書き込まれない)。

## 判定の決まり(両方共通)

- **材料だけで決める**。作品を知っていても、材料に書いていないことは付けない(知識で付けない)。
- **作品の中心にある時だけ**付ける。主人公の属性・主な舞台・物語の主題。脇役・1エピソード・比喩・列挙・趣味の言及では付けない。
  - 外れの実例: 「手を取り合い」→三角関係 / 「受験戦争」→戦争 / 「時代劇が大好きなJK」→時代劇 / 「魔法少女ものから〜まで描いた短編集」→魔法少女 / 「巻末おまけ4コマ」→4コマ / 殺される原因が暗殺者なだけ→暗殺者 / 恋人が刑事なだけの恋愛→警察 / 野球部が舞台なだけの恋愛→野球
- **basis(根拠)は材料からそのまま写す**(4〜25字・1文字も変えない)。材料に無い語句は道具が弾く。題名だけを根拠にしない。
- 短編集・作品集は、本全体の主題の時だけ。収録作の1本だけの題材は付けない。
- 電子版の商品説明(「電子化」「電子書籍で復活」「紙のコミックス未収録」)は内容の根拠にしない。原作小説の紹介文らしい時、題と材料の作品が食い違う時は `混入疑い` で見送る。
- **0個は普通**。迷ったら付けない(付けすぎの方が害が大きい=発見が壊れる)。1頁3個まで。

## ③ themes(要素)の追加ルール

- 使える語は `show` の先頭に出る一覧だけ(和名をそのまま書く)。一覧に無い語(異世界・学園・野球・ボーイズラブ・青春・成長物語・悲劇 等)は使えない。
- 職業・題材系(医療/警察/演劇/お仕事/料理…)は**主人公がそれを仕事・活動にしている時**だけ。
- 関係性系(結婚/同棲/年の差/片思い/三角関係/幼馴染…)は**物語の軸**として書かれている時だけ。

## ④ genres(ジャンル)の追加ルール

使えるキー(英字で書く): fantasy sci-fi mystery suspense horror adventure historical samurai war sports baseball soccer romcom gag gourmet music mecha yokai bl mahou-shoujo isekai supernatural essay 4-koma

| キー | 付ける時(材料に明記) |
|---|---|
| fantasy | 魔法・魔物・架空の王国など、現実にない世界や力が物語の土台 |
| sci-fi | 宇宙・未来社会・科学技術(アンドロイド、タイムマシン等)が土台 |
| mystery | 事件の謎を解く・推理が物語の中心 |
| suspense | 追い詰められる緊張(デスゲーム・陰謀・逃亡・犯罪の駆け引き)が中心 |
| horror | 恐怖・怪異・怪物に襲われることが中心 |
| adventure | 冒険・探検・宝探しの旅が中心 |
| historical | 実在の時代(戦国・江戸・明治・古代ローマ…)が主な舞台 |
| samurai | 侍・剣客・時代劇 |
| war | 戦争・戦場が主な舞台 |
| sports | 競技に打ち込むことが物語の中心(野球なら baseball、サッカーなら soccer も。道具が sports を自動で足す) |
| romcom | 恋愛とコメディの両方が明記(「ラブコメ」等) |
| gag | ギャグ漫画・笑いが主目的と明記 |
| gourmet | 料理・食が主題 |
| music | 音楽活動(バンド・歌・演奏)が中心 |
| mecha | 巨大ロボット・メカに乗って戦う |
| yokai | 妖怪・あやかしが中心 |
| bl | 男性同士の恋愛が本筋。★腐女子が主人公の話・ゲイに囲まれる女性の話・LGBT一般の話は付けない |
| mahou-shoujo | 少女が魔法少女として変身・戦う |
| isekai | 主人公が異世界へ転生・転移・召喚される |
| supernatural | 超能力・霊能力・幽霊が中心(fantasyの世界設定でない、現代の超常) |
| essay | 作者自身の体験を描くエッセイ漫画 |
| 4-koma | 本編が4コマ形式 |

- 汎用キー(drama/comedy/romance/slice-of-life/action)と school/ecchi/mind-game は付けない。

## 段取り(★順番を守る)

1. **試行**: `genres` の id 0〜199 → `themes` の id 0〜199 を判定して `check` を通し、**そこで止まって報告**(書き込み・反映はしない)。報告: 各作業の付与あり頁数・のべ数・キー別件数・skip理由の内訳・迷った例を5つ。
2. Opus が回答ファイルを点検する。直しが入ったらその指摘に従う。
3. **本番**(ユーザから「続けて」が来たら): 残りを最後まで、途中で止まらずに判定する。報告は 2,000頁ごとに1行でよい(返事は要らない)。
4. 全部終わったら作業ごとに:
   ```
   python scripts/_themes-genres-ai.py check <task>
   python scripts/_themes-genres-ai.py apply <task> full --go --model=sonnet-5.5
   ```
   出てきた `.cache/tg-ai/<task>-full-changed-*.txt` を順に反映する。最後の1個以外は `--commit-only`、最後だけ `--push`:
   ```
   python scripts/_reflect-targeted.py --only "$(cat .cache/tg-ai/<task>-full-changed-0.txt)" --commit-only -m "AI要素/ジャンル 反映 1/N"
   ```
   **「減少」が出て止まったら、そこで止めて報告**(--allow-loss は使わない)。
5. 最終報告: 作業ごとの判定頁数・書込頁数・のべ件数・キー別件数・skip内訳・`混入疑い` の頁一覧・check の NG 件数。
