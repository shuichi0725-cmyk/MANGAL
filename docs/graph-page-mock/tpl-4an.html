グラフ頁の見本(4案)

数字はすべて今の本番データ(全 作品)です。ボタンを押すと棒が動きます。
どの案でも同じにするところ:黒地・棒は1色(1位だけ明るく)・棒を押すとそのジャンル/要素の一覧へ進む。

A切り替え式の横棒ランキング

「ジャンル/要素/分野/年代」を押すと、棒が伸び縮みして並び替わる。一番ふつうで読みやすい形。

B年代で動く(順位が入れ替わる)

再生すると1970年代→2020年代へ進み、その年代に始まった作品のジャンルの棒が上がったり下がったりして順位が入れ替わる。

C縦棒(音量メーター風)

棒が下から立ち上がる縦型。分野を押すと全部の棒がいっせいに上下する。横にスクロールして32ジャンル全部。

D絞り込みで比べる横棒

分野で絞ると棒が動く。薄い棒が「全体」、濃い棒が「絞った結果」。全体と比べて多い・少ないが見える。
