★**奇子(saiko.yml)型 = 同一著者・版違いの混在**。T3(著者違い)もT1(出版社違い)もT4(巻数)も主では捕まえられない**最難関クラス**。[[multi_edition_unification_pending]] と同根。

**実例(奇子=手塚治虫)**: standard「全3巻」講談社 が実は2版の混在:
- vol1: ISBN無・1973・label「上」= **通常版(ハードコミックス・大都社・全2巻 上/下)の上巻**(※我々DBは出版社を「講談社」と誤記。本来 大都社)。下巻欠落。
- vol2,3: ISBN 4-06-1087xx・1981 = **手塚治虫漫画全集(講談社・全3巻)の2巻**(3巻中2巻)。

**cm104が権威分解**: 奇子は cm104 に**9エディション**(ハードコミックス大都社1973=2巻 / 手塚治虫漫画全集講談社1981=3巻 / 手塚治虫文庫全集=2巻 / 角川 / 復刊ドットコム…)。各 `schema:numberOfItems`＝正巻数、`schema:brand`＝レーベル、`schema:publisher`、`schema:datePublished`。

**検出信号**: standard内で ①ISBN帯不連続(無ISBN/旧 ↔ 別帯) ②発売年の飛び(1973↔1981) ③cm104に同題で複数版。
**対処(慎重・未実施)**: 除去でなく**版分離＋欠け巻補完**。cm104を版オーソリティに、ISBN帯・発売年で各巻を版へ割り当て直す**専用パス**。9版・巻欠け・出版社誤記が絡むので1件ずつ。簡単なT3混入(著者違い)を片付けた後に着手。
