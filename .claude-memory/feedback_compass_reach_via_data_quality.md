ユーザ(2026-10-05): 「一番大事なのは出せる状態の漫画全てにたどり着く可能性があること」。ただし
「出さないと言うよりは出せるデータを探して出せるようにするがよい。数を多くするのが目的ではなく質を上げつつ
使いやすくて、データが増えて結果増える。という流れが望ましい」。 / 「ある程度有名作が出やすいのはやむなし」。

**Why:** キャッチ無しで書影と題名だけ出す等の「条件を緩めて数を稼ぐ」は札の質を落とす。目的は質と使いやすさ。
**How to apply:**
- 羅針盤の対象条件(書影+キャッチ)は緩めない。行き着けない作品は**材料(あらすじ/巻紹介/紹介文/一次情報)を探してキャッチを書く**側で減らす。材料が無ければ書かない(捏造しない)。
- くじに探索枠を足す等の「有名作の偏り是正」は優先しない(やむなし)。
- 実測(2026-10-04): 全69,514 / 書影あり58,719 / 羅針盤に出られる45,488 / 書影ありキャッチ無し13,231
  = A書ける3,226(1巻2,040)・B要判断23・C宣伝文のみ4・D保留台帳955・D材料なし9,023(楽天空8,388/未照会635)。
  出られる作品のうち行き着けない=61(ジャンル・要素・雑誌なし)。 要素0の作品は出やすさ中央値30回(要素4+=202回)。
  計測= .cache/bench/compass-reach.ts / compass-expose.ts(羅針盤の neighborhood() をそのまま全中央に当てる)。
