2026-09-17、うる星やつらの「巻説明が先頭に出ているか」を判定するのに、
`components/VolumeRow.tsx` の `displayBlocks` を**読まずにPythonで再実装**した。
その際 **2026-09-04 の追補(最古版が書影欠けなら、同じ冊数で書影が揃った版を先頭に pin)を落とし**、
「先頭はワイド版(15巻)、巻説明は3番目」と**誤って報告**した。
実際の先頭は新装版カバー(34巻)で、**巻説明は最初から一番上に出ていた**。
ユーザに画面写真付きで「しかも今現在そうなってる。あなたはなにを言ってるのか?」と指摘された。

**Why:** 表示ロジックは「素直な並び替え」に見えても、**実害から生まれた例外規則が後から足されている**。
再実装は最新の規則を取りこぼす。しかも出力がもっともらしいので誤りに気づけない。

**How to apply:**
- ★**表示の結論を出す前に、その描画コンポーネントを開いて最後まで読む**(sort だけでなく、
  その後ろの pin / 例外 / 再並べ替えまで)。 `displayBlocks` は sort の**後**に pin が来る形だった。
- 再現スクリプトを書くなら、**実装のコメントに書かれた日付付き追補を全部拾ったか**を自問する。
- ユーザが画面を見て言うことは観測事実。 自分の計算と食い違ったら**まず自分の再現を疑う**
  ([[feedback_absence_needs_verification]] と同根)。
