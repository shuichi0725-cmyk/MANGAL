2026-09-07。 巻抜け充填([[volgap_fill_pipeline_2026_09]])で踏んだ型。
**MADBのレーベル表記ゆれ等で1本の刊行runが同じ頁の2つの版タブに割れている**と、
片方の穴を埋めた瞬間にもう片方と**同じ本が二重表示**になる。 巻の実在は正しいのに追加が誤りになる。

## 実例
- **エースをねらえ!** 版[0]「通常版(マーガレットコミックス)」v1-18(v8欠) と
  版[1]「マーガレットコミックス(1975)」v8-18 — 同じMC。 どちらの穴を埋めても他方と重なる
- **東大一直線** 「ジャンプ・コミックス」と「ジャンプ・コミックス(1977)」
- **ぼくの動物園日記** 「ジャンプ・コミックス」と「**Jump comics**」= 和名↔英字の表記ゆれ。
  ★両版とも**ISBNを1本も持たない**ので、レーベル名の文字列比較では同一と判定できなかった
- **プラモ狂四郎** 「KCデラックス」v5(1990-05-17・ISBN無) と
  「コミックボンボンデラックス」v5(候補9784063131284・1990-05-17) = **同じ本**
- **ジャイアント台風** 「KCスペシャル」と「ヒット・コミック」に同じISBNが提案された

## 見分け(= `scripts/_volgap-adjudicate.py` に実装)
- **G8**  同じ頁の**同レーベル**の別版が既にその巻番号を持つ → 保留。
  ★ただし **ISBN連番で位置が確定している時(g_isbn=o)は通す**(あぶれもん= 754259<**754266**<754273)。
  止めるのは「隣の巻にISBNが無く帯を錨に取れない」頁だけ
- **G8b** 別版に **同じ巻番号 かつ 同じ発売日** が在る → 同一の本 → 保留(プラモ狂四郎型)
- **G8c** 対象の版が**ISBNを1本も持たず**、同じ頁の**別のISBN無し版**が既にその巻番号を持つ → 保留
  (ぼくの動物園日記型。 レーベル名が和名↔英字で一致判定できなくても落とせる)。
  ★片方がISBNを持つ頁は正当な別版なので対象外(**ワイルド7**= 徳間書店版2001 と デラックス版1987)
- **G7**  同じISBNが2つ以上のターゲットに提案されたら、証拠(o)の多い版だけ採る

## 教訓
巻抜けの是正で「巻を足す」前に、**その頁が刊行run分裂を起こしていないか**を先に見る。
分裂している頁は**巻を足す案件ではなく版を直す案件**。 自動統合は禁止([[imprint_split_arms_type]]
[[edition_run_split_arms_wide_type]])なので、充填器は保留に落として報告するのが正しい。
