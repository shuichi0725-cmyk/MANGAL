## 設計で決めたこと(理由つき)
- Haiku は**指すだけ**(文面を打たせない): 作り話の材料が混ざると、後段の「根拠が材料に一字一句あるか」検査を素通りするため。
- 取得は**魚**(TinyFish)かAPI: Claude標準の WebFetch は要約を返し、生の文面が残らないため。
- 後段(付与)で入れるつもりのもの: 「芯」と「在る」を分ける(長い記事は書いてある≠芯)/ 語彙外の候補は付けずに台帳へ(語彙に無いと近い別語に寄せる=ひきこもり型)/ 人名・あだ名・題名は根拠にしない(ヒッキー型・ヒップホップ応援団型)/ AniList のタグが濃い作品で伏せて答え合わせ。
