### ★「令」頁に3編が潰れていた
旧 `higurashi-no-naku-koro-ni-rei` は v1-2=**鬼熾し編**、v3-4=**色尊し編の3-4巻**という接ぎ木で、
色尊し編1-2と星渡し編1-2はどこにも無かった。canonical で鬼熾し編2巻に絞り、残り2編を別頁化。
- `…-rei-ryukishi-2011` は題に編名が欠けていた → 「ひぐらしのなく頃に礼 賽殺し編」に。**令(rei)と礼(rei)が同音**で紛らわしいので注意。
- 鬼隠し編の著者に **方条ゆとり**(綿流し編・目明し編の作画者)が誤混入 → NDL責任表示「鈴羅木かりん 作画」で是正。

### ★掲載誌が20頁ぶん誤っていた(種3 AI fill)
`monthly-shonen-magazine`(講談社!)が解 皆殺し編に、`shonen-ace`が月刊コンプエース作品に、
`manga-action`が月刊アクション作品に、等。`magazine-corrections.yml` で全て是正。
そのために `data/magazines.yml` に7誌追加: `gangan-powered` `gangan-wing` `gangan-joker`
`gangan-online` `big-gangan` `young-ace-up` `monthly-action`(55→62誌)。
★**月刊コンプエース≠月刊少年エース / 月刊アクション≠漫画アクション / ガンガンパワード≠月刊少年ガンガン** は別誌。

### ★promote のバグを1件直した
**予約頁(preorder-pages)が magazine-corrections を通らない**ため、新規4頁の magazine が空のままだった。
2026-08-03 に同じ型(ジャンルseedが予約頁に届かない)を直した箇所のすぐ上に追加。
= **本流の決定点(種2経由)にある処理は、予約頁の合流路にも要る**という型。他にも同種の穴が残っている可能性。

### ★ユーザ裁定(2026-08-08)= 除外の基準
「**アンソロジーだから除外ではなく、纏められないものを除外**」。
ひぐらしは **出題編・回答編・番外編(個人作家の撰集を含む)が本編**で掲載する。
**作画がたくさんいるアンソロジー型**は本編ではない。[[exclusion_priority_policy]] の「③纏められないもの」と同じ基準。
- 非掲載にした = `higurashi-no-nakukoro-ni`(**無印slugを占有していた**) = 宙出版ツインハートコミックス
  『ひぐらしのなく頃に ～the Nth case～』。作画30名・本番に在るのは第5/6/10/11/12巻だけ(1-4と7-9欠落)。
  題に「アンソロジー」の語が無く promote の DROP パターンをすり抜けていた。
- 登録しない = `ひぐらしのなく頃に煌 妖戦し編(努)`(9784803002775・アース・スター 2011)= アンソロジー型で著者なし。
- 収集しない = ひぐらしデイブレイクPortable / ひぐらしの哭く頃に 雀 / 雀 -燕返し編- / デイブレイクPortable MEGA EDITION。

### ★一迅社「◯◯撰集」= 個人作家の番外編(掲載する)
DMC編集部編の『奇譚撰集』『新奇譚集』(NDL題に「コミックアンソロジー」・著者欄が**会社名「一迅社」**)とは**別物**。
撰集は1作家1冊が基本。★**種2に在るのに頁が無い孤児シリーズ**だったので preorder-pages で新規登録:
`…-kuriyama-renji-senshuu`(栗山廉士/函満し編) / `…-ondi-senshuu`(オンディ/罪宿し編) /
`…-mochizuki-kako-senshuu`(望月菓子/春青し編) / `…-wakarukana-senshuu`(**判奏=ワカルカナ**/鬼愛し編)。
- `…-itagaki-hako-senshuu` は ①著者が**オンディ**に化けていた(種2 sid69511 の series_authors が誤り)
  ②2冊とも**種2で number=1** のため dedup で怨絶し編が消えていた → canonical で2巻に振り直し。
- ★`data/manga/`(SRC)は**gitignore=再生成物**なので、孤児シリーズの頁化は preorder-pages が唯一の永続ルート。
- 読みは全て**楽天 titleKana** で確定(判奏=ワカルカナ 等、推測不能なものが多い)。
