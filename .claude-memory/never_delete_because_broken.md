**「壊れているから非掲載にする」を禁止する。** 壊れているものは**直す**か、載せずに**保留台帳**へ。

**Why**: 2026-08-08、日次蒸留で『新装版 熱愛プリンス お兄ちゃんはキミが好き』を
「v1-12が全て同じ発売日=巻構成が壊れている / publisher未解決 / 索引skip」を理由に deny した。
**全部誤診**だった:
- 同一発売日 = **実際に同日一斉刊行**(通常版v1-12=2020-06-26 / 新装版19冊=2023-09-08 / カルチュア版25冊=2026-10-13)
- publisher未解決 = 消す理由でなく**マスターに足す**話(ネクストF / カルチュア・エンタテインメント)
- 実体は **4版・全68巻**の実在作(TVドラマ化)。ユーザ指摘が無ければ永久に消えていた。

★ユーザの言葉: 「**最悪なのが本当にある物を消してしまったとき。私は気がつけない。不自然に数字がある場合は気がつく**」
= 欠陥には**非対称性**がある。変なslug・変な題はユーザが見つけてくれる。**存在しないものは誰にも見えない**。
だから「見える欠陥の修正」より「**見えない消失の防止**」を優先する。

**消してよい3類型(これ以外は消さない)**:
1. **書籍でない** — 特典しおり/ポスター/グッズ(★`isbn13` が 978/979 始まりでない = 楽天独自コード)
2. **掲載scope外** — 画集・アメコミ翻訳・非漫画・ユーザ裁定の「纏められないもの」
3. **実体が別頁へ移った** — 統合・slug変更(この場合は巻が減らないことを必ず確認)

**How to apply**:
- 消す前に「これは上の1-3のどれか」を明示する。当てはまらなければ**保留**(載せないが台帳に残し直せる状態に)。
- ★**日付が揃っている/publisherが未登録/索引skip は「異常」ではなく「未整備」**。調べれば理由がある。
- 全巻回収は **JPRO → 楽天 → NDL** の順で粘る([[jpro_pubrights_search]])。
  熱愛プリンスの元版1-19は**JPROにしか無かった**(楽天は30件上限で欠け、NDLは単話売のみ)。
