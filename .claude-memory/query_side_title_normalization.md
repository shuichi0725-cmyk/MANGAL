# クエリ側の題正規化 (= 怪物事変22巻型、2026-08-05確定)

**照合(match)側の正規化を強化しても、検索クエリに頁題の生文字列を投げていると候補が0件で返り、どのゲートにも到達せず「未発見」になる。**

**Why:** 頁題「怪物(けもの)事変」の生クエリ→楽天0件・NDLは括弧付き時代(1-20巻)のみ。ソース側の題は途中巻から「怪物事変」(括弧読み無し)に変わっていた。括弧を剥いたクエリなら楽天でv22が即出た。巻抜けハントで「live未発見/NDL未発見」と記帳された中にこの型が5作35巻分埋まっていた(是正8巻: 怪物事変22/じつは義妹5-6/勘違いの工房主7,10-12/ねえトライして2)。

**How to apply:**
- 外部照会(楽天/NDL)のクエリは **生題と剥き題(括弧読み除去 `[(（][^)）]{1,12}[)）]` を strip)の両方**で投げる。照合側は norm/norm_np の両対応(既実装)。
- 「未発見」台帳を疑う時は、まず**題に括弧・装飾を含むslug**を抽出して剥き題で再走する。
- ★**最後の網=素の検索**(2026-08-05 ユーザ裁定「何も付け足さずに検索してみて」): 精密クエリ(title=/creator=束縛)で出ない時は **`anywhere="題"` の束縛なし検索**で表記揺れごと拾う。実証=「誰にも言えない(秘)」の欠番は納本欠落と誤診しかけたが、素の検索で**番号なし副題題の巻**(誰にも言えない(秘)禁断の恋 等)が出た。巻番号は **NDLのseries欄の号数**(「ガールズポップコレクション ; 13」)で確定できる。9桁ISBNはチェック桁X脱落型= `isbn="…X"` をNDLに投げて同一レコード解決で検証(推測でなく裏取り)。v3,4,12,13適用済。
- ★**分冊版ノイズ型**(SERVAMP 22,23型 2026-08-05): 電子分冊版が数百件ある人気作は、題検索の取得枠(50×数ページ)が分冊版で埋まり**単行本レコードが枠外に沈む**。解= **`creator="著者名"` 束縛**で引き直す(分冊版も著者は同じだが件数が桁で減り単行本が入る)。素の検索(anywhere)も同様に沈むので、大量ヒット時はcreator束縛が正解。
- 診断の順: 精密クエリ → 剥き題クエリ → **素の検索(anywhere)** → それでも無ければ取得不能(納本欠落/電子のみ)。「取得不能」の宣告は素の検索を通してから。
