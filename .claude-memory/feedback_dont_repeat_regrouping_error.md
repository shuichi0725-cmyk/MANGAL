★今の本番DBの誤り(分裂/版混在/誤ISBN/巻数違い)は、**「MADBから再グルーピング＋私の解釈」を何度もやった結果**。cm104も「基本正しいが時々誤る」(例: 北斗の拳に巻数8の変なcm104レコードC254625)。**最大の危険源は私の解釈層**。

**Why:** 確信を持って再導出→上書き、を繰り返すと誤りが累積・固定化する。実際それが現状を生んだ。[[clustering_unit_is_series]] [[merge_needs_external_proof]] [[series_fragmentation_rootcause]] と同根。

**How to apply（ISBN/巻数是正の鉄則）:**
1. **監査only・本番不変**がデフォルト。一括自動適用はしない。
2. **単一ソースを信じない**=多数決。cm104巻数 ＋ 楽天種ISBN実在 ＋ ISBN連番の連続性 ＋ 現DB、が**一致した時だけ高信頼**。食い違いは人手判断へ(自動決定しない)。
3. **私の推論を毎回明示**(根拠の各ソース値を並べる)→ apply前にユーザが解釈違いを捕まえられる形。
4. **小バッチ・確証付き・可逆**(別台帳に提案、上書きでなく追記/フラグ)。誤りを後で戻せるように。
5. **統合/マージは最も危険**(過去の破壊源)→ 最後・最小・人手確認のみ。デフォルト分離維持。
6. 着手順=最も確実な所から。例「このISBNは楽天題で別作=この作品に属さない(=誤ISBN除去)」は高信頼。**再付与/再グルーピングは後回し**で人手確証。
