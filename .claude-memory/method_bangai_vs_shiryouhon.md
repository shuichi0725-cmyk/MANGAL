x.5 巻や番外巻を頁に載せてよいか(= 漫画か資料本か)を **2段の機械判定**で切る。
2026-09-06 に x.5 候補31件へ適用し、掲載7件 / 除外24件に確定した。

## ① NDL by-ISBN の**実題**を見る(楽天題では分からない)
楽天題は「ホリミヤ（10．5）」のように**巻番号しか出さない**ことが多く、資料本と漫画が区別できない。
NDL の `dc:title` は副題まで持つので一発で分かる:
- ホリミヤ10.5 → `ホリミヤ10.5 official fanbook`
- テニスの王子様30.5 → `テニスの王子様イラスト集30.5`
- うさぎドロップ9.5 → `うさぎドロップ9.5 : 映画・アニメ・原作公式ガイドブック`
- SERVAMP10.5 → `SERVAMP : OFFICIAL GUIDE BOOK`
- 田中くん5.5/13.5 → `official tanakabook` / `memorial tanakabook`
- 繰繰れ!コックリさん5.5/8.5 → `公式ググ本` / `妖怪ググ辞典`
- 絶園のテンペスト9.5 → `原作完全ガイド&カラーイラストブック`
弾く語 = ガイドブック / ファンブック / 公式ガイド / official guide / official fanbook /
キャラクターブック / イラスト集 / 設定資料 / 調査報告書 / 辞典 / 攻略。

## ② ★楽天価格が「通常巻の中央値」の何倍か(NDL題が素っ気ない時の決め手)
資料本は判型が大きく単価が高い。 **1.5倍以上なら資料本**が実測できれいに出た:
| 巻 | x.5価格 | 通常巻中央値 | 比 | 判定 |
|---|---|---|---|---|
| 青春×機関銃 7.5 | 942 | 628 | **1.50** | 資料本(除外) |
| 不機嫌なモノノケ庵 6.5 | 942 | 628 | **1.50** | 資料本(除外) |
| 恋愛ラボ 8.5 | 1026 | 619 | **1.66** | 資料本(除外) |
| モテキ 4.5 | 502 | 660 | 0.76 | 漫画(掲載) |
| 範馬刃牙 10.5 | 460 | 499 | 0.92 | 漫画(掲載) |
| 30禁 5.5 | 499 | 499 | 1.00 | 漫画(掲載) |
NDL題が無副題でも②で落ちることがある(= ①だけでは足りない)。

## ③ 楽天 caption があれば決定打
「番外編を集めたサイドストーリー集」「短編集と本編のその後のエピローグ」= 漫画 /
「公式ファンブック第二弾。描き下ろし漫画、インタビュー、人気投票の結果」= 資料本。
★caption で **小説**(くまクマ熊ベアー11.5=PASH!ブックス)や
**既刊の再編**(Wonder!14.5=「14巻のセレクトでもれた13話分を収録した特別編集版」)も落ちる。

**Why:** 番外巻は「載せてよい漫画」と「載せてはいけない資料本」が同じ題・同じ巻番号で並ぶ。
題だけでも価格だけでも切れず、2段にすると人手ゼロで9割方決まる。
**How to apply:** 候補が出たら ①NDL by-ISBN → ②価格比 → ③caption の順。 通らないものは載せない。
