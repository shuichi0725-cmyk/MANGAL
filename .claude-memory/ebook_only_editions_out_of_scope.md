★**電子限定版は現状スコープ外**(2026-07-26 GANTZで確認)。 将来 **柱で楽天から回収**する方針。

## 何が起きたか
ユーザ提供のAmazonスクショで『**GANTZ カラー版 OSAKA編**』(YJC DIGITAL)の存在が判明。
- **当方(種2/MADB) = 0件**。 MADBは**紙の書誌(ISBN基準)**なので、ISBNを持たない電子限定版は**原理的に入らない**。
- **Wikipedia にも記載なし**(紙の単行本37巻/愛蔵版3巻/文庫18巻のみ)。
- ★**楽天Koboには在る**: 「GANTZ カラー版」で25件超。 かっぺ星人編1-4 / オニ星人編1-2 /
  チビ星人編1-2 / OSAKA編 … **全て 奥浩哉/集英社/2013-08-19**、★**エピソード単位の分冊**。

## 掲載しない理由(現時点)
- ISBNが無く Kobo/Kindle 独自IDのみ → **ISBN基準の同定・重複排除が効かない**
- 粒度が紙の巻と対応しない(章単位分冊)。 独立頁にすると分冊が並んで本編が埋没する
- 電子オリジナル/分冊配信は近年激増 = 数が膨大

## 方針(ユーザ 2026-07-26)
★**柱(アイドル運転)で既存作品の電子版情報を楽天からそのうち取る**。
取ったあとの置き場は「**本編頁の電子版情報**」が自然(独立頁にしない)。
現行スキーマは版=紙前提なので、結線時に設計変更が要る。 [[version_tabs_stock_ebook]]
