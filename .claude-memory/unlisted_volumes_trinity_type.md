## 署名
『トリニティセブン 七人の魔道士と日常風景 15.5』(9784040721446)は **種2に在り本編頁も在る**のに、
種2側で別クラスタ(`qid:…|name:トリニティセブン`)に **number=15** で入っていて本編15巻と番号衝突し、
どの頁にも出ていなかった。

## ★既存監査の死角(だから新設した)
- **孤児series監査** = 「そのseriesの巻が**1本も**出ていない」が条件。 部分掲載クラスタの取りこぼしは対象外。
- **Sugar&Spice型** = ★**楽天キャッシュの題**が「親題+巻番号」を名乗るのが条件。 題の形が違うと拾えない。
- **巻抜け仮想** = 番号の**穴**を見る。 15と16が連続している所に挟まる 15.5 は穴にならない。

## 2本立て

### ① 種2駆動(楽天非依存)= 汎用
本番に出ていないISBNを全部見て、持ち主の頁が既に在るものだけ残す。
- 照合 = SIBLING(同seriesの別巻が本番に在る=最強) / TITLE(正規化題一致・ルビ括弧除去) /
  SLUG(ラテン題→本番slug) / NEAR(題の包含=弱いので芯外)。 全部**著者ゲート**つき(同名別作品952件対策)。
- **番号状態で4分割** ← これが芯を人が裁ける大きさにする鍵:
  | 状態 | 初回実測 | 意味 |
  |---|---|---|
  | DUP | 18,729巻 | 同番号が別ISBNで既在。 ★トリニティ15.5もここ。 実測は**別版(新装版/文庫)の1巻**が主で薄い |
  | VOL0 | 2,140巻 | number=0 → `_audit-vol0-hidden-first.py` と `vol0-show.yml` の領域 |
  | **MISSING** | **224巻** | ★本当に欠けている巻 |
  | YEARNUM | 18巻 | 西暦が巻番号に化けた誤番号 |
- ★芯 = MISSING × 強照合 = **107巻 / 72頁**。 実例= ドラベース1-11(てんとう虫C) / 蒼竜の側用人1-4(花とゆめC) /
  魔法科高校の劣等生 侵攻編4-6 / 皆様の玩具です1-3 / うちの3姉妹17-19 / 悪役令嬢後宮物語 王国激動編6-7(2026-04)。
- 除外は promote 本体を import して適用(adult/非漫画/画集/imprint/版種/題patterns)+ `volume-exclude.yml`。
