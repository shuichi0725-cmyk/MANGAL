## ★結論(先に読む): 孤児seriesは「出すべき取りこぼし」ではない

`_audit-orphan-new-series.py` が出す **45,606件(2026-09-02)** は、
**「サイトに出ていない=出すべき」ではない**。 ★**Fable 5 が調査して「出すものではない」と裁定済み**。
2026-09-06 に Opus 5 が実データで検算し、 裁定は正しいと確認した。

★この行は **セッションを跨いで繰り返し誤読されてきた**(Opus 5 が3回「最大の構造穴・未掲載47,631」として
改善提案に挙げ、 ユーザに「毎回これを指摘する」と指摘された)。 数字が大きく検出器名が
「orphan / 未掲載」なので **取りこぼしに見える**が、 実体は下記のとおり **除外対象と統合対象**である。

## 実測(2026-09-06・`docs/production-diagnostics/orphan-new-series.tsv` × `.cache/torikoboshi/harvest.jsonl`)

### 巻数 = 98.1%が単巻
- 単巻 **44,722** / 2巻 683 / 3巻以上 **わずか201**。 「埋もれた長期連載」は存在しない。
- 単巻の主体 = BL 5,453 / TL・レディコミ・ハーレクイン 6,149 / レーベル空 5,348 / その他単発 27,772。
  imprint上位= Bamboo comics 1,214 / ハーレクインコミックス★キララ 843 / Emerald 730 / Missy 726 /
  花音 543 / Gush 493 / Chara 388 / ディアプラス 373 …= **単発読切のBL・TL・レディコミが主体**。

### 材料が無いので新規登録protocolでは載せられない
- 楽天ハーベスト44,933件のうち **caption(あらすじ・ジャンルの材料)が在るのは42.5%だけ**。
  **59.7%(27,235)はcaption無し** = genre確定不能。 書影無し 23.7%。 楽天ヒット自体無し 1,762。
- [[new_manga_registration_order]] は **genre≥1 等の必須メタが揃わない作品は「登録保留=載せない」**と定めている。
  埋めれば載る、ではなく **埋められないから載せない**。 捏造は禁止 [[feedback_accuracy_is_the_goal]]。

### ★多巻(3巻以上201件)の中身 = ほぼ全部が「既存頁の分裂クラスタ」
`_exists.py --title` で実照合して**本番に在ることを確認済み**:

- 孤児側の行は **ラテン表記・新装版・編集版・別レーベル**で別 series_key に落ちた分身。
  TSVの `class` 列は **題の完全一致しか見ない**ので、これらが全部「未掲載」に落ちている(検出器の弱点)。
- 残りは **コンビニ廉価再録**(Akita top comics wide / SP pocket / BIG COMICS SPECIAL / HMB / King series /
  Gコミックス / jump remix / マンガショップ)= [[exclusion_priority_policy]] の除外優先度②そのもの、
  **編集し直し版**(ドラゴンボール 少年編/フリーザ編/ピッコロ大魔王編)、
  **外国語版**(ブラックジャック[韓国語]22巻 / 鉄腕アトム[韓国語]18巻 / どろろ / アトム今昔物語)= scope外、
  **アンソロ・ムック**(らき☆すたコミックアラカルト / SHUFFLE!コミックアラカルト / はるか通信 / 世界名作劇場)。
- ★決定打: **ユーザが既にdrop裁定した「スゴ盛!本当にあった…」(commit 354b6250c=実話系4コマ雑誌の増刊)が
  今も「未掲載」として上がってくる**。 検出器は裁定済みdropを覚えていない。
- 題も著者も本番に見当たらない3巻以上は 80件、 そこから上記(ラテン表記の既存作・コンビニ・外国語・アンソロ)を
  引くと **真に新しいのは10件前後**(傲慢の時代/せいぶつ部の田辺くん/100年の推し/君に贈るキヅタ/
  田舎暮らしの魔草薬師/恋するサイコの白雪くん/ダイダラ 等、 いずれも2022-2026年刊)。
  = **日次蒸留(予約ハーベスト)と月次蒸留の頁化ルートで拾う対象**であって、45,606の話ではない。

## 帰結: これは「頁化案件」ではなく

1. **除外**(コンビニ廉価・外国語版・アンソロ・材料なし単巻) と
2. **既存頁への統合**(版タブ / 種4 / series-merge)

の2つ。 ★**頁化したら二重頁を量産する** = 直近で是正した [[year_suffix_slug_survey]] ハンター×ハンター型・
[[imprint_split_arms_type]] ARMS型の再生産になる。 だから出さない。

## 元の発見(機構としては正しい・記録として残す)

promote は `_promote-bulk-v2.py:2929` = `for ypath in sorted(SRC_DIR.glob("*.yml"))`(SRC_DIR=`data/manga`)
+ 末尾で `data/seeds/preorder-pages/*.yml` を合流する **元頁駆動**で、種2(db-v2)起点で新頁を作る処理は無い。
新規シリーズが頁になるのは **予約ルート(日次)** と **取りこぼし頁化(`_torikoboshi-genpages.py`、3ゲート付き)** だけ。
これは**設計として妥当**(無差別にDB駆動で頁を吐くと上記の分裂・コンビニ本・材料なしが全部出る)。

## ★検出器は是正済み(2026-09-06 実装・ユーザGO)

`scripts/_audit-orphan-new-series.py` が **class列で機械照合**するようになった(行は消さない= 情報は落とさない):
- `既存頁(題一致)` = 正規化題の一致。 ★**ルビ括弧を除去**(「六道の悪女(おんな)たち」→本番と一致)。
- `既存頁(slug一致)` = ★**ラテン題→本番slug**。 カナ⇔ラテンは正規化では届かない
  (City hunter→city-hunter / CROWS→crows / Monkey Turn→monkey-turn / master keaton→master-keaton / Happy!→happy)。
- `外国語版(scope外)` = 題に[韓国語]等、 または全ISBNが非9784。
- `裁定済みdrop題` = non-manga-drop/drop_keys を **題**でも突合(key照合だけでは別クラスタのスゴ盛型が素通りしていた)。
- ★**著者ゲート**: 題が一致しても著者が1人も重ならなければ `同題別著者(要確認)` にして **芯に残す**
  (同名別作品952件が正当に併存= 隠さない。 実例= 本番 kenkaku-shoubai-saitou2003=さいとう・たかを版 と
  孤児=大島やすいち版 は別の漫画)。
- ★あいまい一致(著者×題の包含)は **class を動かさず注記列 `類似頁`** に留める。
  包含で class を決めていた実装は 呪術廻戦≡ / 東京卍リベンジャーズ〜場地圭介からの手紙〜 /
  デッドマウント・デスプレイ外伝 / ばくおん!!外伝 のような **本物の別作品を親作品に吸わせて隠して**いた。
- 列追加: `既存頁slug` / `類似頁` / `材料`(楽天ハーベストの紹介文・書影の有無) / `著者既掲載`。
- ★**imprint文字列で「コンビニ廉価再録」を機械判定するのはやらない**(promote本体の注記どおり
  Gコミックス/SPコミックス/マンサン等は正規レーベルで一括不可)。 再録・別版・分裂は全部「著者が同じ」に乗るので
  `類似頁`/`著者既掲載` で人が裁く。

出力2本: 全件 `orphan-new-series.tsv` + ★**芯 `orphan-new-series-core.tsv`**
(= 2巻以上 × class∈{未掲載, 同題別著者}。 `--core-min-vols N` で可変)。
実測 **47,631 → 芯 844 / 直近12か月 515**。 月次サニティ(`_monthly-distill.py` DETECTORS)の行数も
**芯TSVを見る**ように変更済み。 ★見るのは芯の直近12か月だけ。

## ★第2の誤読燃料 = live-isbn索引の陳腐化(2026-09-06 ユーザ発見「トリニティセブンは元々たくさんある」)

古い索引で回すと **既に解決した案件が孤児として復活する**。 実害:
- 索引が 09-02 のままで、 **09-03 の Sugar&Spice 型結線で本編頁へ入った トリニティセブン 19〜34巻**を
  監査が「まだ出ていない」と3クラスタぶん上げていた(12巻/3巻/1巻)。
- 検算: 本番 `trinity-7-shichinin-no-masho-tsukai.yml` は **1〜34巻を保持**、
  9784040727806(19)/9784040752433(30)/9784040758305(32) は全部載っている。
  トリニティセブンは本番に **7頁**(7人の魔書使い/レヴィ忍伝/リーゼクロニクル/アナスタシア聖伝/
  トリニティセブンさん/セブンデイズ/リヴィジョン)在って、欠けてなどいなかった。
- ★恒久策= `newest_src_mtime()` で **data/manga.v2 が索引より新しければ自動で作り直す**(実装済)。
  「promote後は --rebuild」の注意書きだけでは付け忘れが静かに数字を膨らませる。
- 索引再構築後の正しい数字 = 全件 **47,553** / 芯 **833** / 直近12か月 **514**。

★db-v2 側では本編が5クラスタに割れている(1-18 / 19-29,31 / 30[subに末尾ピリオド] / 32-34[qid無しkey] /
15.5)。 本番頁は結線済みなので **表示は正しい**。 唯一 本番に無い実体 =
**9784040721446「トリニティセブン 七人の魔道士と日常風景 15.5」(2017-01-07)** = 番外編の短編集で、
db-v2 は number=15 で持つため本編15巻と衝突する(小数巻は本番に前例0)。 = 裁定マター(要否・置き場)。
コミックアンソロジー(9784040707853)は title_contains で正当drop。

**Why:** 大きい数字と「未掲載」という名前が「取りこぼし=直すべき」に見えるが、実体は
掲載scope外・既存頁の分身・材料なしの単発読切。 出すと二重頁とコンビニ本で本番を汚す。
**How to apply:** 改善提案にこの数字を挙げない。 孤児TSVを見る時は **3巻以上×既存頁照合済み×材料あり**まで
絞ってから読む。 関連: [[exclusion_priority_policy]] [[new_manga_registration_order]]
