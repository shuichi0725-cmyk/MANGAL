作業PC M5_ULTRA は有線LANの口が2つ(Realtek 2.5GbE ×2)。
- **イーサネット 3** = 固定IP **192.168.0.146**(GW/DNS 192.168.0.1)。他機器はこのIPでD共有(D / ムービー / 動画2 / 本)を見ている。
- イーサネット 2 = DHCP(192.168.0.147 等)。

2026-10-18 実踏: ケーブルがイーサネット 2 側に挿さっていて .147 になり「D共有が他から見えない」。口を挿し替えて解決。
イーサネット 2 に .146 を手入力すると「IP 設定を保存できません」= イーサネット 3 が未接続でも .146 を保持しているため(重複不可)。
**How to apply:** 共有が見えない報告 → まず `Get-NetAdapter` でどちらの口がUpか確認。一番早い直し方 = ケーブルを挿し替える。
