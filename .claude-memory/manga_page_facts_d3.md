2026-10-07 ユーザ「漫画ページの基本情報の見せ方…SEO的に悪い影響が出なそうな範囲で…羅針盤などと色を合わせて」。
見本2往復で決着: 1回目 0現状/A枠を色/B見出しを札/C糸の帯/D コマ割り(白い紙)/E一文/F 3枚の札 → ユーザ「CDFが良い。Dは白だと眩しいので黒系で比較したい」
→ 2回目 D1墨のコマ/D2網点のコマ/D3コマ割り(+C・F)→ **「D3適用で」**。

## 形(D3)
- 3段のコマ: 出版年(網点の地)/ 著者 | 連載誌 の**斜めの枠**の2コマ / ジャンル(橙の塗り)・要素(青の枠)。 その下に従来どおり「同ジャンル検索 →」+羅針盤マーク。
- 各コマ左上の**写植箱 = 羅針盤の糸の色**(著者=金 #f2c14e・連載誌=緑・出版年=紫・要素=青・ジャンル=橙)。 出版社が主役のコマは線の色(糸が無い)。
- 黒い紙 #121211 に生成りの線 #e9e5d8(`.theme-d3 .mf`)。 既定(明るいテーマ用)は羅針盤のコマと同じ白い紙に黒い線。

## 実装(commit は git log「基本情報欄」で引く)
- 部品 `components/MangaFacts.tsx`(サーバ描画・JSなし)/ 見た目 `components/manga-facts.css`(Tailwind の新クラスを足さない)/ 判断 `lib/mangaFacts.ts` / テスト `lib/mangaFacts.test.ts`。
- ★色は CSS に直書き → **テストが `app/compass/compass.ts` の KIND_COLOR と突合**(羅針盤の色を変えたらテストが落ちる=作品頁も直す)。
- 掲載誌が無い作品 = **79.6%**(本番索引 69,515作)→ 右のコマは「出版社」が主役(写植箱は線の色)、分野は小さい行。
- 縦積み(斜めをやめる)= 著者3人以上 or 著者名合計>14字 or 原作+その他が約2行超(`stackPeople`)。 4人以上は大きい字をやめる(`manyPeople`)。 著者1人が92.9%。
- 「その他」(監修・編集など・約2%)は著者のコマの小さい行(文字だけ=従来どおりリンク無し)。
- ★SEO の約束(見本に明記して提示済): リンク先・本数・文字・並び(題名→基本情報→あらすじ→巻)・h1 は旧 `<dl>` と同じ。 違いは「連載誌」と「出版社」の順が入れ替わったのと、著者の間に「・」が入ったことだけ。
- 押した時 = そのコマが糸の色に染まる(`:has(a:active)`)。 チップは高さ約26px(押しやすさ)。
