2026-10-01、書影あり・キャッチ無し 17,994作に Kobo EbookSearch で紹介文を問い合わせた(`scripts/_kobo-caption-harvest.py`・再開可・約5時間)。
完全一致(題+著者)で紹介文あり 8,562 / 照合を緩めた場合のみ 2,269 / 無し 7,163。材料は `.cache/kobo-caption/harvest.jsonl`。
Sonnet 5.5 が strict 分からキャッチ 5,811作を書き(見送り: 材料不足1,405・成年向け1,107・範囲外174ほか)、Opus が点検した。
羅針盤の対象(書影&キャッチ)は 10-02 時点で 45,488(10-01 朝 35,964)。キャッチ無しは残り 13,157。

**Why:** 楽天の紙の本の紹介文が枯れた層に、電子版の紹介文が届いた。電子版は古い作品でも配信が最近なので紹介文が付いている。

**How to apply:**
- 書かせる時の型(点検で出た誤り): ①電子版の商品説明(「電子化」「電子書籍で復活」「紙のコミックス未収録」)をキャッチに使う ②短編集の「表題作ほかN編」の数え違い(題名一覧に表題作を含む/含まない が混在) ③題の「Ⅱ」を巻数と誤読 ④文の途中で切れる(名詞の前の「の」で終わる) ⑤原作小説の紹介文が当たる(原作者が著者欄にいる時)。①は26件中20件・②〜④は計約20件/5,811。
- 緩めた照合の 2,269作は未着手。別作品(スピンオフ)・傑作集/セレクション・後の巻 が混ざるので、1件ずつ判断させる。
- 点検は「全件の3か所整合 → 数字/カタカナ語が材料に無いもの → 文末の途切れ → 無作為50件」の順が効いた。関連: [[onevol_catch_themes_enrich_2026_10]] [[feedback_agent_fanout_token_cost]]
