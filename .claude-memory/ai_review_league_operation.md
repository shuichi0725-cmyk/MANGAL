ホーム corner9「AI書評家リーグ」= **同じ課題図書・同じ依頼文を実在の各社AIに渡し、出力をそのまま並べて読み比べる週刊企画**(♥で今週のベスト書評家)。表示は**会社名＋モデル名**(例 Google Gemini / OpenAI ChatGPT / xAI Grok / DeepSeek / Anthropic Claude)。三世代(リコ等の創作ペルソナ)とは別物。

**分担(2026-06-14ユーザ確定・★訂正済)**:
- **Claude(私)**: ①課題図書(完結作・既出除外・私の自由選定)を決める ②共通プロンプトに作者『作品』を入れて確定 → これだけ。★**予定パックには私の書評文を入れない**(ユーザ: 「あなたの文はいらない、プロンプトだけ貼って」。書評本文が混ざると使いづらい)。
- **ユーザ**: 同じプロンプトを**各AIに貼って生成**→各社の本文を「会社+モデル名」付きで私に返す(私はAPIで他社を回せない)。★**顔ぶれは開放(固定しない)**: 無料最新モデル＋**上位モデルも込み(例: Claude Opus 4.8 1M, GPT等)**。上位を入れる方がエンタメ性が高い、とユーザ要望。Opus等のClaude系もユーザが生成して名前付きで渡す(私が先に書かない)。人数は週ごと可変。
- **予定パックの形**: 各節=「課題図書(作者『作品』・slug・完結)＋コピペ用プロンプト」**のみ**。コードブロックで貼ると使いやすい。
- **Claude**: 全社分を `data/seeds/ai-reviews.yml`(週/節キー)に組んで格納→その週が来たら自動表示。

**作り置き**: 私が予定パック(節ごと=課題図書＋プロンプト＋私の書評)を先出し→ユーザが他社分を埋める。初期バッファ8節。**公開待ち在庫が4節まで減ったら私が「補充どき」と通知**(常時稼働でないので作業時に在庫報告＋4以下で警告。完全自動化は週次チェックを別途仕込む)。

**共通プロンプト(確定)**: 「あなたはプロの編集者で、本の紹介をするプロです。ネタバレなしに、なるべく長く紹介文を書いてほしいです。ストーリーの説明ではなく、なるべく長い読み応えのある文で、読者に『読みたい』と思わせる文を書くのが仕事です。今回の題材は 〇〇『△△』です。」
- 変更は全員一斉・現状変更予定なし。冒頭「プロの編集者」を雑誌『ダ・ヴィンチ』編集者にする案は“タビンチ”の解釈待ち(未確定)。

**進捗**: 節1=幽☆遊☆白書(デモ)。第1弾パック=節2〜9(鋼の錬金術師/DEATH NOTE/進撃/鬼滅/約ネバ/SLAM DUNK/寄生獣/銀魂)を `docs/ai-review-pack-01.md` で配布済(2026-06-14)。seed/ページ自動化(週キー)は未実装。
