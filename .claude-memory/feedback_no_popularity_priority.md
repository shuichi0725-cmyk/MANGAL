ユーザに**複数回**言われた: 「人気順にやりたがるが無駄。全部やるんだから。」

私の悪癖 = 残タスクを pop(AniList人気)でソートして「有名作から」着手しようとする。**これは無駄**。最終的に全件やるので、順位付け・選別・「まず有名作」の枠組み自体が不要な思考コスト。

**How to apply**: 巻抜け等の一括per-caseは、remainリストを**端から全部**処理する(pop順ソートしない・「famous優先」と言わない)。各件で「確証→修正 / 怪しい→飛ばす+記録」を淡々と。順番を考える時間を使わない。確証できないものを飛ばすのはOK(無理にマッチさせない)が、それは「pop低いから後回し」ではなく「確証取れないから」が理由。

**Why**: 全件処理が前提なら順序は成果に無関係。pエラーソートは私の自己満足で、ユーザには無駄に映る。
