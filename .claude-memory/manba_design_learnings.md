manba.co.jp トップ+ランキング頁の実観察(2026-07-06)。[[discovery-strategy-and-refs]]の具体化。

**構成(上から)**: おすすめ→なんでもランキング/勝手におすすめランキング/属性別ランキング→みんなのリスト→Webマンガ→クチコミ(新着/人気)→#1巻応援→雑談広場→思い出せないマンガ/おすすめ教えて→マンバ通信(編集記事+記事ランキング)→注目ユーザー→著者。

**MANGALに使える見せ方**(コミュニティ機能は真似しない方針):
1. **切り口ランキングの乱立**(「勝手におすすめ」「なんでも」)= 数を打つ。MANGALはDB強者なので「巻数最長」「最年長現役作家」「同日発売最多」等の機械生成ランキングを量産できる=マンバに無い土俵。
2. **記事タイトルの文体**が固有名詞+数字+感情(「島耕作のスピード感は、『君に届け』を2コマで置き去りにする」「ドカベン31巻のすごさについて言いたくて……夏」)。AI書評リーグ/今日の一冊のコメント文体の手本=具体が引き。
3. **#1巻応援**タグ文化=新作1巻を推す棚。予約②③(新作1巻ドラフト)の見せ方に直結: 「今月の新作1巻」棚は「応援」の文脈で出すと刺さる。
4. **テーマ別リスト**(男女バディ/戦国時代/ダークファンタジー/2020年代の完結傑作)=人力リスト。MANGALはgenre×tag×年代×status の掛け算ランディングで自動生成可能(genre/[key]の発展形)。
5. 書影が常に主役(h3=作品名+書影カード)。リストでも必ず書影列。
6. 「今日読んだマンガを書くだけのトピック」=ハードル最低の参加装置(参考のみ)。

**やらないこと**: クチコミ/広場/ユーザー機能(コミュニティ先行と戦わない)。
