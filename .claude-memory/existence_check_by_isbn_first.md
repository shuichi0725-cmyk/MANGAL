**新規頁を作る前に `python scripts/_exists.py --isbn <判明した全巻のISBN>` を必ず通す。**
題検索(`--title`)は**完全一致**なので、次の全部で素通りする:
- 感嘆符の有無/全半角 … `どっきりエンジェル` ↔ 本番 `どっきり!エンジェル`
- 中黒の有無 … `グリーン・パラダイス` ↔ 本番 `GREEN PARADISE`
- ラテン/カタカナ … `ファイナル・ミッション` ↔ 本番 `Final Mission`
- ラテン/ギリシャ文字 … `χの歌声` ↔ 本番 `Xの歌声`

**Why**: 2026-08-08 に**同じミスを2回**やった。
①『どっきり！エンジェル』= 既存 `dotsukiri-angel` に気付かず新頁を作り**二重頁**を発生させた
(ユーザがpreviewで発見)。題が「どっきり**!**エンジェル」で検索に掛からず、存在チェックに使ったISBNが
よりによって**本当に欠落していた巻**だったため二重に素通りした。
②『ジョーカー・シリーズ』= 「欠けている3冊」と報告したが**3冊とも存在**していた(題がラテン表記)。
作る直前にISBNで引いて気付いたので事故にはならなかった。

**How to apply**:
1. 全巻回収(NDL/楽天/Wikipedia)で**判明したISBNを全部**集める。
2. `_exists.py --isbn a,b,c,...` で一括照会。**1件でも当たれば新規登録ではなく既存頁の是正**に切り替える。
   ★ユーザ提供の1本だけで判断しない(提供されるISBNは「欠けている巻」であることが多い=当たらなくて当然)。
3. 作った後も **ISBNと正規化題で全数照合**して重複ゼロを確認する
   (正規化= NFKC + 空白/中黒/!?:～-&。、. と括弧を除去して lower)。
   この事後照合で『ひぐらし解 祭囃し編』の接ぎ木(v1-4が罪滅し編の巻)も見つかった。
4. 二重になった時は**種2駆動の既存頁を残し、自作の preorder-page を撤去**する
   (種2側を消しても次のフルpromoteで復活して再発するため)。
