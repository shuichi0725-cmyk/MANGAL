2026-10-08 羅針盤の「星図を描いています…」(初期の星図案の名残)の言い換えに、比喩の候補6つ(糸を張っています/方角を合わせています/旅の支度をしています 等)を出したら、
ユーザ「準備中 now loading など 普通でよい」→ 「準備中…」にした。 続けて「動いてるのを分からすためにアニメ流すとか」→ 見本5案(針/糸/枠/点/網点)を出すと
「全部とても良い。ランダムで全部出せる?」→ 5種ランダムで実装([[magic_shelf_virtual_bookstore]])。

**Why:** 状態を知らせる文言は、読んで一瞬で分かることが役目。 凝った比喩は「何をしているのか」をかえって分かりにくくする。 楽しさは文言でなく動き・絵で出す。
**How to apply:**
- 読み込み中・失敗・空の状態などの文言は、まず普通の言葉(準備中・読み込み中・見つかりませんでした)で書く。 比喩の候補を並べて選ばせない。
- 見た目(アニメ・絵柄)は遊んでよい。 見本は複数出し、「全部使う(ランダム)」も選択肢として想定しておく。
- ただし1例からの一般化。 違う反応があったらここを直す。
