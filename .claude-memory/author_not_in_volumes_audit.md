★**著者誤混入層**(2026-08-02 ユーザ発見『よろしくメカドック』)。**メカドック1件だけ是正済み、残りは宿題**とユーザ裁定。

## 何だったか

次原隆二の単独作『よろしくメカドック』の著者欄に **秋本治** が入っていた。是正は
`author-role-corrections.yml` の **`remove`**(誤クレジット人物の完全除去)。

判定の根拠3点:
- 秋本治(Q1321466)が **series_key の qid(Q11544888=次原隆二)と不一致**
- **楽天の巻書誌8巻ぶんに一度も現れない**
- 秋本治の紐付き先は**約105件すべて「こち亀」関連**で、この1作だけが浮いていた

## 検出器 `scripts/_audit-author-not-in-volumes.py`

判定 = 頁の著者が**その頁のどの巻の書誌にも現れない**か。初回 **8,680件/5,120頁**。
出力 `docs/production-diagnostics/author-not-in-volumes.tsv`。

★**突合元は楽天の `author`**。当初 種1(MADB metadata101 665MB)で突合しようとしたが、
**古い書籍は種1に無い**(メカドックのジャンプ・コミックス12巻は1件も収録なし)ので判定不能だった。
楽天は書影取得で全頁ぶん引いてあり被覆が広い(56,295 ISBN で照合できた)。

★**他のsignalでは切れないことを実測済み**(同じ道を辿らないため):
- series_key の qid と著者 qid の不一致 → **8,625件**。大半が正当な原作+作画(武論尊×池上遼一)
- さらに「両方 writer_artist」で絞る → **4,784件**。まだ武論尊×原哲夫(北斗の拳)、
  アンソロジー(花とゆめプラチナ)、原作小説家(阿刀田高/橋田壽賀子/デュマ・フィス)が大半
- 役割データが粗い([[author_roles_state]] 101-cleanが役割を剥がした)ため、
  **巻の書誌に載っているか**という一次情報でしか切れない
