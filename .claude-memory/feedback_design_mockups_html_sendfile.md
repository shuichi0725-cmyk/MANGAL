2026-10-03 羅針盤の下の札(キャッチ/詳細/進む)の相談で、この型が4往復で決着した。
1. 案A〜D(方向性: 黒ガラス/糸の色の札/紙の札/下段一列) → ユーザ「案B背景黒を中心にボタン違い」
2. B1〜B6(色違い) → 「b3を基本に形違い」
3. S1〜S7(形違い) → 「詳細は左下でパターンを変えて」
4. D1〜D7(詳細の出し方) → 「D2」= 実装(app/compass/compass.css の「6. シートの見た目」)

**Why:** ユーザはAndroidで確認する。文章の説明だけでは色・形を選べない。番号で返せる見本だと1語で次に進める。
1回の見本で全部を決めず、ユーザが「どの軸を固定するか」を毎回指定してくれる(背景→色→形→位置)。

**How to apply:**
- 見本 = 単体HTML(scratchpad)を `SendUserFile display:render`。スマホ幅(max 420px)・実画面の該当部分だけ切り出す・**実データ**(本物の書影URL・実際の文言/ボタンラベル)を使う。
- 各案に**2状態**(何も選んでいない/操作中)を並べる。末尾に「本番では出ない部品」の注記。
- 返事は表(案・何を変えたか・ねらい)+おすすめ1つ(理由つき)+「番号で」。案は6〜7が上限。
- ★見本に描いた**位置関係は実装でも検算**する(D2実装後、札が伸びて上の「広げる」帯が隠れた= 見本は固定高さで描いていた)。
