★掲載対象判定の**微妙な境界**ルール(2026-06、 ユーザ実物確認で確立)。 単純文言/imprintだけで一括判断せず、 ★**描き手・収録内容・レーベルの組合せ**で裁定。

**① 映画/アニメ由来の区別(★最重要)**:
- ★**映画/アニメのコミカライズ(=漫画家による描き下ろし漫画)= 掲載対象(keep)**。 例: コミックス プロジェクトA子2(結城信輝ら描き下ろし、 1987 JB)。
- ★**フィルムコミック(=アニメ静止画をコマ割りしただけ)= 掲載対象外(drop)**。
- ★判別 = ★**漫画家(描き手)の有無**。 例: SF新世紀レンズマン → 三浦みつる著=コミカライズ(keep) / 三浦みつる無し+講談社アニメコミックス=フィルムコミック(drop)。
- ★**「アニメコミックス」imprintを一律dropしてはいけない**(コミカライズが混在)。 個別に描き手で確認。

**② コンビニ廉価再録レーベル = drop**([[non_manga_drop_cleanup]]):
- ★**KPC(講談社プラチナコミックス)= コンビニ向け廉価再録**(既刊の抜粋/収録)= drop。 DROP_IMPRINT_PATTERNSに追加済。 signal=初出「○巻〜○巻を収録」+激安(366円等)+専用レーベル。
- ★**DX/デラックス(KCDX 等)は正規装丁=drop しない**(誤爆注意)。
- 他社のコンビニ再録(英語表記variant等)も漏れ得る→月次監査の新imprintカバー率flagで検出。

**③ フリガナ(title_kana)に副題/英題/巻内容が漏れ込むケース**([[volume_split_merge]]の検出器流用):
- MADB ja-hrkt由来で、 title_kanaに ★**読みでなく副題/収録作/英題**が入る。 例: チェンソーマン→「Chain saw man犬とチェンソー」、 クトゥルフ神話→「まだ見ぬカダスを夢に探して」。
- ★検出 = title中カタカナ連がフリガナに無い + 主題不一致。 ★是正 = pykakasiで正読み再導出(英字/数字は手動カタカナ化、 当て字は守る=旋風Z→センプウゼットハリケーンゼット)。 21+件是正済。
- ★galaxy(slug問題)とは別パターン。 ★月次サニティ監査の新flag。


## 特典小冊子まとめ本 = keep(2026-07-14 ユーザ裁定)
- 例: 「傷モノの花嫁 小冊子まとめ本」(講談社・店舗特典小冊子の商業まとめ)。
- **纏められる(=作品に関連づく)商業出版物は掲載する**。広義には漫画そのものでない可能性があっても「漫画に関係するもの」として出す方針。
- コンビニ廉価再録(むこうぶちVol.N型=本編が既にある再録)とは区別: そちらはdrop。
