Kindle収穫(_kindle-asin-harvest.py)の予約起動(sleepで時刻待ち)は、**ユーザが時刻を指定して明示的に頼んだ時だけ**。こちらの判断で「1時間あけるため」等と仕掛けない。

**Why:** 2026-11-25 ユーザ「直接頼むから予約はしないで」(429後1時間あけるため15:30予約をHaiku経由で仕掛けたら止められた)。2026-11-26 ユーザが「02:00に再開して」と時刻指定し、確認に「よい」と答えた = 指定があれば予約可に更新。
**How to apply:** 時刻指定が無ければ予約せず「何時以降なら回せる」と伝えて待つ。予約する時はSTOP札を見てから起動する形にする。運転条件の最新ユーザ指定 = KINDLE_ASIN_PACE=12・KINDLE_ASIN_BUDGET=0(上限なし)・200以外1回で即停止(厳守)。関連 [[kindle_link_browser_not_app]]

**429の観察(11/25-26):** 11/25 直近24時間7,224回・5,193回で429。11/26 は 6,057回(17:16)・6,381回(20:10)で429。5,000回を切っても出る = 上限は24時間回数だけではない。429後に1時間あけて再開しても約170頁で再び429。再開は24時間呼出が4,000回台に落ちてからが安全寄り。
