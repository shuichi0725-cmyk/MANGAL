2026-08-31 ユーザGOで確定したSEO title方針:

- **A案採用**: `app/layout.tsx` のtitleテンプレート = `%s | 漫画・コミックのMANGAL`(全66k頁に「漫画」「コミック」が乗る。シーモア型=ブランドサフィックスにキーワードを背負わせる定石)。
- **C案採用**: 作品頁のfallback description に「漫画全巻一覧」(catch/synopsis有りの頁は対象外)。
- **B案見送り(ユーザ裁定)**: 作品頁titleに「(漫画)」を直接挿す案は不採用。再提案しない。
- /shinkan のtitle = 「漫画コミック 新刊発売日一覧」(検索クエリ「漫画 発売日」狙い)。
- 同日、ページ側で「| MANGAL」を自書きしていた7頁(shinkan/color-manga/contact/rankings/sansedai-archive/adult-triage/zenshuu)の**二重サフィックスバグ**を是正済(templateが付けるのでページ側は書かない)。app/browse と app/page.tsx にはこの旨のコメントが元から在る。
- **注意**: サイト全体のtitle変更なのでGoogle再評価で順位が数週間揺れうる。「順位が下がった」報告が来たらまずこの変更日(2026-08-31、本番反映は次の機能蒸留/週次)を思い出す。

**Why:** 「漫画コミック探すならMANGAL」的な露出をユーザが希望。詰め込み(漫画コミック連結を毎頁)はGoogleのtitle書き換えを招くためサフィックス集約にした。
**How to apply:** 新ページのmetadataでは「| MANGAL」を書かない(templateに任せる)。titleへのキーワード追加提案はA/C路線の範囲で。関連: [[seo_index_coverage_state]]

## ★2026-09-18 改訂: 作品頁だけ D案(「| MANGAL」)へ短縮 = ユーザ裁定

A案(全頁「| 漫画・コミックのMANGAL」)は **作品頁では表示されていなかった**ことが実測で判明した。

| | 実測 |
|---|---|
| サフィックス「\| 漫画・コミックのMANGAL」 | **12.5 全角相当** |
| 作品頁 title の中央値(n=1,000) | **38.5 全角** |
| 日本語SERPの表示上限(約30全角)に収まる作品頁 | **0.1%**(=ほぼ全頁が切れる) |
| 「\| MANGAL」(4.5全角)に短縮した場合 | 中央値 30.5 / 収まる **48.8%** |
| ★著者頁(20,203) | 中央値 **27.0** / 収まる **97%** = 切れていない |

★**切れるのは末尾=サフィックスそのもの**なので、現状の検索結果には「| 漫画・コミッ…」という
尻切れだけが出て、**キーワードもブランド名 MANGAL も両方表示されていなかった**。
ついでに著者名(`| 高橋留美子`)まで表示外へ押し出していた。

### 適用範囲(ここが D案の肝)
- **作品頁(69,352)のみ** 短縮 = `app/manga/[slug]/page.tsx` の generateMetadata が
  `title.absolute` で「<題名> | MANGAL」を返す(layout の template を迂回)。
  ★`app/manga/layout.tsx` を足す手は**使わない**(69,352ルートのRSCツリーにsegmentが増える)。
- **著者頁・ハブ/コーナー頁は現状維持**。切れていない=キーワードが実際に表示されているため。
- og:title は従来どおりサフィックス無し(ブランドは `og:site_name = MANGAL`)。共有カードは不変。

### 判断の根拠(効いている証拠が無い側を削った)
汎用語で取れているのは**全部ホーム経由**(Bing実測: 「日本漫画」209表示49クリック2.0位・
「漫画 db」「漫画データベース」「漫画検索」)。作品頁の表示は**全部作品名クエリ**で、
サフィックスの「漫画・コミック」が効いている証拠は GSC/Bing のどちらにも無かった。
★ただし **表示が切られること ≠ ランキング信号として無視されること**。Google は title 全文を読む。
失うのは表示とCTR、という整理でユーザが D を選択した。

**注意**: 8/31 と同じく**サイト全体の title 変更なので Google 再評価で数週間順位が揺れうる**。
「順位が下がった」報告が来たら、まず 2026-08-31 と **2026-09-18** の2つの変更日を思い出す。
**B案(作品頁titleに「(漫画)」直挿し)は引き続き不採用・再提案しない**(= 作品頁から「漫画」の語を
戻す手段は無い、と承知のうえでの裁定)。
