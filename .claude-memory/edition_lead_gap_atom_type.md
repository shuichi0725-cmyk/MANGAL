2026-09-07 ユーザ報告「鉄腕アトムが漫画内分裂している。これ系を機械的に調べて直せそうなものは直して」。

## 症状と正体
鉄腕アトムの頁は版タブが15本あり、うち「講談社コミックス(1993)」が **v6,8-15** から始まっていた。
隣に「KCスペシャル(1987) v1-7」が並ぶので **1本の作品が2つに割れている**ように見える。
★しかし正体は分裂ではなく **その版の先頭巻がまるごと落ちていた**(= 統合ではなく**充填**が正解)。

**機械証拠(楽天ローカル題索引 `.cache/isbn-title-map.json` を prefix で引くだけ):**
- `4-06-1013xx` = KCスペシャル **全7巻**(013056=1巻 … 013117=7巻) = 完備
- `4-06-3133xx` = 講談社コミックス **全15巻**(133585=1巻 … 133820=15巻。 133813=大図鑑は関連書)
→ **別ライン**。 v1-5,7 は種2に在るのに canonical seed が editions を置換して消していた。
是正後 = 講談社コミックス版 **1-15 完備**。

## 検出器(月次サニティ #29 に登録済)
`scripts/_audit-edition-lead-gap.py` = 版が ①2冊以上 ②ISBNを1冊以上持つ ③最小巻>1
④同じ頁の別タブが下の巻を持つ ⑤最小巻<=20。 初回 99版/95頁/ターゲット294巻。
`--emit-targets` で充填ターゲットTSVを出し、[[volgap_fill_pipeline_2026_09]] のチェーンにそのまま流せる。
★正当な途中開始(新装版が5巻から復刻等)も拾うが、5ゲートで**実在する本が見つかった時だけ**埋まる
自己限定型なので、検出の粗さが誤適用にならない。

## 併せて直した充填器の2つの穴 (`_volgap-local-fill-v2.py`)
1. **EXISTS の候補を「最古の日付」で選んでいた** → 同じスコア(版元/ISBN連番/日付/著者)で選ぶ
2. **fresh が1件でも在れば fresh だけ見ていた** → fresh と exists を**合わせた全体**から最良を選ぶ
これが無いと、鉄腕アトム v1(9784063133585)/v2(9784063133608) は種2に在るのに、
朝日ソノラマ1975・秋田1995 の別版が fresh として選ばれ「版元prefix不一致」で棄却されていた。
★是正後、本体チェーンを回し直すだけで 29巻(天才バカボン/サバイバル/俺の空 等)が追加で拾えた。

## 成果(2026-09-07)
先頭欠け充填 69巻/24頁 + 第2巡 29巻/9頁。 大きい復元= MF動物病院日誌 v1-17 /
ドカベン スーパースターズ編 文庫版 v1-14 / ルパン三世 双葉文庫 v1-8 / 天才バカボン v4,6-13 /
サバイバル(SPコミックス+SP Pocket 13巻)。 残gap 379 → 374。
