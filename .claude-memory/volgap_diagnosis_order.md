★**巻抜けを見たらまず「その巻は種2に在るか」を引く**(`.cache/db-v2.sqlite` の volumes を isbn13 で)。
在否で処方が正反対になる。 2026-07-26 に14作をper-caseで通して型が出揃った。 [[volgap_mostly_undermerge]] の続報。

## 4つの型と処方

**① データ誤り(そもそも抜けていない)**
別作品/非漫画が紛れて番号を占め、あるはずのない欠番を作る。
 例=美少女戦士セーラームーンS の「28巻」= 講談社のテレビ絵本(絵本)。 → non-manga-drop で消すと欠落も消える。

**② 種2に在るが別seriesへ誤配属 + 番号衝突でdedupに負けて非表示**(★最も見つけにくい)
 例=彼岸島 最後の47日間 の11巻が本編「彼岸島」sid19264に同居し、本編の同番号巻に毎回負けていた
 (番号1にISBNが14個ぶら下がる)。 カムイ外伝のBIG COMICS 2巻/17巻が文庫・叢書クラスタsid31665に紛入。
 ★処方 = **種4で正しいseries_keyへ結線** + **誤配属元のslugへ volume-exclude**(将来dedupの勝敗が反転しても混入しない)。
 ★`_exists.py --isbn` が「無」= 本番のどこにも出ていない、を必ず確認してから入れる(出ていれば二重化する)。

**③ 真のMADB取込もれ(種2に無い)** → 種4 volumes-supplement が正解。
 ★NDLに無くても楽天にはある例がある(怨み屋本舗REBOOT 10・11 / ANIMAL X 原始再来 6-9巻)。 片方で諦めない。
 ★楽天の題に巻数が無いことがある(ロックマンX2 2巻=題「ロックマンX2」)。 **ISBNの連番位置+発売日の位置**で同定できる。

**④ 誤った番号付けが欠落を偽装している**(★見落としやすい)
 - 火の鳥《オリジナル版》復刻大全集 = **別巻1・別巻2(火の鳥2772ストーリーボード集)が「1巻・2巻」として載り**、
   真の1-4巻が丸ごと欠けていた。 ストーリーボード=絵コンテ集で漫画でない → volume-exclude + 真1-4を種4。
 - ベルサイユのばら外伝 = **巻抜けでなく版混在**。 外伝は月刊Jam連載全4話=**本来1冊**の作品なのに、
   1つの通常版に中央公論新社2003年版と実業之日本社1985年版を「1巻」「3巻」として同居させ、
   存在しない2巻の欠落を作っていた → `edition-overrides.json` で5版に分離。

## ついでに出る型
**コンビニ廉価再録本**が独立頁として巻抜けに見える。 日本文芸社「〜スペシャル」(Gコミックス)は
巻数でなく**エピソード単位の再編集**(喧嘩ラーメンスペシャル=名物ラーメン誕生編…全7冊)。 本編頁が別にあるので drop。

## 手順(この順で引く)
1. `python scripts/_ledger.py <slug>` で来歴 → 2. 頁の巻+ISBN+発売日を出す →
3. **NDL(title検索)で正の全巻構成**を取る → 4. 欠番ISBNを**種2で在否判定** →
5. 在る=②/無い=③ → 6. 楽天でISBN直引きして実在+書影確認 → 7. 種4/exclude/overrides を選ぶ →
8. `_reflect-targeted.py --only <SRCstem>` ★**slugでなくSRCファイル名**(例 kamui-gaiden の実体は `kamuigaiden.yml`)。
   間違えると「promote後にファイルが無い」で検証ゲートが止める(データは無傷)。
