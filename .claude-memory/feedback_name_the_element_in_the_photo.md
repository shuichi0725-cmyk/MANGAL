2026-09-07。ユーザから **「最悪な間違いをしてる。左が一覧検索になってる。これは一切いらない。
写真の一覧検索の右の検索を全ページに出して」** と強い指摘を受けた。

## 何を間違えたか

「左の検索を全ページに出して」を、**自分が直前に左へ置いた物(HomeSidebar=一覧へ飛ぶリンク集)**のことだと解釈した。
ユーザが指していたのは**その右にあった絞り込みパネル(FilterPanel)**。1画面まるごと作り直しになった。

★**曖昧さに気づいて番号付きで確認まではした**のに、選択肢を「自分の実装した物をどう扱うか」で組んでしまい、
**正解(=絞り込みパネル)が選択肢に1つも入っていなかった**。確認したのに外した、が最悪の形。

## How to apply

- 写真つきでUI指示が来たら、**まず写真に写っている要素を実名で列挙する**
  (例: 「左端=検索窓+一覧表/絞り込み+ジャンル32+コーナー」「その右=種類/連載状態/巻数/分野/ジャンルの絞り込み」)。
  そのうえで「どれのことですか」と聞く。**自分の実装を出発点にしない**。
- ユーザは位置関係(「〜の右の」「〜の上に」)で指す。**位置語は最優先の手がかり**として、
  画面の左から順に要素を数えて対応させる。
- 選択肢を出す時は、**写真に実在する要素だけ**を候補にする。抽象的な言い換え(「見た目を揃える/移す」)は
  対象が特定できていない証拠。

**Why:** UI指示は画面上の物理的な位置で語られる。実装者の頭の中の部品名で受けると、
確認したつもりで対象を取り違える。手戻りが1画面単位で発生する。
