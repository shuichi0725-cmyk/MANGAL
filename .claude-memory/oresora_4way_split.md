★2026-09-06 ユーザ報告「刑事編とくっついてる」+ NDL書誌TSV(81行)+マンガペディア → **4作品が1頁に同居**していた。
頁分割の手順は [[ousama_shitateya_4part_split]] のPoJ式をそのまま再利用(stub→canonical→overrides→promote→reflect)。

| 頁 | 中身 |
|---|---|
| `orenosora` | **本編**(週刊プレイボーイ 1976-79)。大型本8巻+PB comics 9+スーパーPB 4+文庫1-7+**ホームコミックス傑作集7(新規追加)** |
| `ore-no-sora-keiji-hen`(新) | **刑事編**。YJC全7巻(1980-81)+YJC-SP全6巻(1993)+文庫8〜11巻 |
| `ore-no-sora-sanshirou-hen`(新) | **三四郎編**。YJC-SP 全8巻(1992-12〜1994-05) |
| `ore-no-sora-yasuda-ippei`(新) | **安田一平、新たなる旅立ち**。SCオールマン全3巻(2001) |

- ★1993年のYJC・スペシャル版タブの中で **刑事編と三四郎編が混在**していた(ISBNで初めて分離できた)。
- 著者の誤混入 **高橋よしひろ** を除去(NDL責任表示は本宮ひろ志/本宮ひろ志とチューリップ組のみ)。
- 版の表記ゆれ統合: 「スーパー・プレイボーイ・コミックス」と英字「SUPERPLAYBOY COMICS」(ARMS型)。
- 総集編(ヤングジャンプ特別編集1980 / 1000p総集編2003-05)は非掲載方針で載せない。

## ★再利用できる手筋
- **ISBN帯の連番から候補ISBNを作って楽天キャッシュに当てる**。三四郎編1巻を当初「所在不明」としたが、
  帯が 4-08-8751-71〜78 で連番だったので 9784088751719 を作って照会 → 「俺の空（三四郎編1）」1992年12月・
  書影ありで**確証**。★これは推測で埋めるのではなく **候補を作って裏を取る**手であり、だろう運転ではない。
- **ユーザが持ってきたISBNがコンビニ廉価版のことがある**: 9784081132270「俺の空三四郎編（1）」は
  series=**集英社ジャンプリミックス**=非掲載。ただし「1巻が存在する」裏付けにはなり、本命へ辿れた。

## 残(判断保留)

7巻→2巻で1980年版の再刊と断定できない。いまは刑事編頁の**別タブ**に置いてある。別作品と判れば頁を分ける。
