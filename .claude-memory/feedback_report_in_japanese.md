ユーザへの報告・途中経過・質問は、**必ず日本語**で書く(コード中のコメントや commit メッセージも既存どおり日本語)。

**Why:** 2026-09-24、予約harvestの自動細分を実装した後の完了報告が丸ごと英語になっていた。
ユーザは「英語になってるけど終わったの？」と、作業が終わったのかどうか自体を判断できなかった。
会話の要約(コンパクション)をまたいだ直後に起きたので、要約後は言語の手がかりが薄れやすい。

**How to apply:** 要約から再開した直後の最初の発話と、長い作業の後の完了報告は特に、日本語になっているかを確かめてから出す。
英語で書いてしまったと気づいたら、次の発話で日本語で言い直す。
