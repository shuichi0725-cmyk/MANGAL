★**種1→種2 の脱落は「作品でないもの」が大半**。 種2再ビルドで救う価値は低い、と裁定した(2026-07-26)。

## 発見の経緯
既存の取りこぼし監査は **種2→本番** しか見ておらず、**種2に入る前に消えた**分は構造的に検出できない
(ユーザ指摘「本番ではなく種と比べて出てないっていってるのが含まれてない?」)。
→ `scripts/_audit-seed1-lost.py` を新設して可視化。

## 実測
- 種1(metadata101-clean) の ISBN付き **354,343** → **種2に無い 9,797巻**
- ★脱落理由は **全件 `no_creator`**: `schema:creator` が `['', {'@value':'','@language':'ja-hrkt'}]` と空。
  `_build-series-v2.py` Phase2 はクラスタキーが「著者+題」なので著者不明の本を捨てる
  ([[series_fragmentation_rootcause]])。
- 成年1,339 / 非成年8,458。 題×レーベルで2巻以上に纏まるのは1,168シリーズ(5,470巻)。
- そのうち アンソロジー213 / 雑誌・ムック254(On blue 46巻・アックス44巻) /
  グルメ系オムニバス28(思い出食堂61巻=巻ごとに執筆陣が違う) は明示的に対象外。
- 残り **673シリーズ(2,833巻)** を本番ISBN照合 → **670が真の未掲載**。 ★全件ISBNあり。
- ★**ローカル楽天キャッシュで引けたのは 205/1,705 ISBN(12%)** だけ
  (既存キャッシュは本番掲載ISBN中心に集めたため。 本番外の層は入っていない)。
- 引けた131シリーズの性質: **アンソロジー系108(82%)** / 単一著者21 / オムニバス誌2。
    30巻 オメガバースプロジェクト=著者「アンソロジー」 / 15巻 悪役令嬢ですが…=同 /
    10巻 マジキュー4コマ=「マジキューコミックス編集部」
  → **MADBの creator が空なのは正しい**(本当に単一著者がいない)。

## 裁定
★**種2の再ビルドはしない**。 理由:
 ①脱落の大半は構造的に「作品でない」(アンソロジー/雑誌/ムック)
 ②真の作品は **数十シリーズ規模** (チーム・フェニックス=手塚治虫 / 滝田ゆう落語劇場 等)
 ③再ビルドは既存クラスタID・結線への影響が大きい
→ 真に救うべきものが見つかったら **per-case** で既存の取りこぼし機構
  (`_torikoboshi-genpages.py`)で拾う。 [[orphan_series_promote_is_srcpage_driven]]
