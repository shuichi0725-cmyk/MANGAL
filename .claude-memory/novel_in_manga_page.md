# コミック頁への別作品混入 (2026-08-29 型化)

ユーザ報告「9巻だけラノベ汚染」(断罪された悪役令嬢は、逆行して完璧な悪女を目指す)から追跡した型。

## 入口 = 柱⑨「続巻逆照合」の帯救済

汚染巻は 種4 の `source: rakuten-trailing`(= `_check-recent-ongoing-volumes.py`)が入れていた。
同スクリプトは著者一致ゲートを持つが、**「ISBN出版者記号(帯)が一致すれば著者不一致でも通す」**
という作画交代型の救済がある。**原作小説は同じ版元から出るので帯が一致し、素通りしていた**。

→ 2026-08-29 に **`novel_suspect()`** を追加(帯救済より前に判定):
  頁が原作者と作画者を別々に持つ時、候補の著者欄の人が**全員 原作者**(作画者が1人も居ない)なら弾く。
  作画交代型は「原作者+**新しい**作画者」で2名以上になるのでゲートに当たらない。
  旧queue(orig_authors無し)でも頁YAMLから読み直すfallback付き。

## 事後検出

`scripts/_audit-novel-in-manga-page.py`(種4全巻 × ローカル楽天キャッシュ1パス)。
signal = 「楽天authorに原作者は居るが作画者が居ない」。
★**偽陽性が多い**(楽天の著者欄が片方しか埋まっていないだけ)。初回27件中、実害は3頁5巻だった。
必ず1件ずつ楽天/NDLで裏取りしてから `volume-exclude.yml` へ。人名の異体字(濵/濱)は畳むこと。

## 初回で見つかった実害(是正済)

- danzai…akujo-o-mezasu 9巻 = 原作ラノベ(楢山幕府・1399円)。真の9巻は 9784868541370
- tate-no-yuusha-…-girls-side-story 26/29巻 = **本編**(藍屋球作画)が全3巻のスピンオフ頁に混入
- bird-black-maaketto 1/2巻 = 2000年の別作品『バード』(青山広美単独)。真の1/2巻は 9784801957794/9784801960237

**Why**: 題が同じだけの別物(原作小説・本編・同題の旧作)は、巻数も発売日もリンク先も全部ずらす。
しかも「巻が増えた」ように見えるので巻抜け監査では気付けない。

**How to apply**: 題検索で巻を拾う仕組みを作る時は、**版元(帯)一致を著者不一致の免罪符にしない**。
