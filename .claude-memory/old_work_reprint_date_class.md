1981年より前の本は初版にISBNが無く、ISBNが付いているのは後年の刷か新装版。 そのため頁の日付が2通りに化ける:
1. **後年刷の日付**: 昭和極道史 文華版 = 5/6/7/11/13/15巻が1981年刷の日付(初版は1978〜80)。 8/10巻も初版の年月とずれていた。
2. **別版の日付の流用**: エスパー魔美 = てんとう虫コミックス(1987年新装・97840914150xx)に、楽天 salesDate が
   マンガくん/少年ビッグ版の1978〜83年の日付を返す(3巻=1987・4巻=1989と巻ごとにばらばら)。 8/7の統合時にそれを信じて
   てんとう虫版を1978年の通常版にしていた。 ★**楽天の旧作の発売日は版の証拠にならない**。

**直し方**(canonical 本体へ書く):
- 日付 = NDL の初版の年月(ISBN無しの記録: マンガくんコミックス等)。 ISBN = 後年刷/MADB のものを添付(=昭和極道史 v1-3 の既存方針と同じ)。
- 原版がISBN無しなら巻は `isbn13: null` で置く(推測で連番ISBNを作らない)。 年しか分からない巻は `'1987'` のように年だけ。
- 版の構造は Wikipedia の単行本節で確かめる(魔美=6版。 8/7は5版で原版が抜けていた)。

**Why**: 8/7 の魔美の統合は楽天の日付を信じて版を取り違え、ユーザが同じリンクをもう一度渡すことになった。
**How to apply**: 1970年代の作品で日付が巻順に逆行していたり、1981年の同じ日付が並んでいたら、この型を疑う。
ユーザは NDL 検索結果の TSV(全列)を添付してくることがある = 初版年月の一次資料としてそのまま使える。

魔美の最初のタブを原版(ISBN無しの巻あり)のままにするか。
