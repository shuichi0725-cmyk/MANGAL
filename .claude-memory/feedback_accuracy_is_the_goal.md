ユーザ厳命(2026-06-28、 NDL発見作のページ化で繰り返し叱られた末):

> 「ndlから登録するのは必要だが改善点がある。**フォルダ名と適当に作者などを入れるのは絶対ダメ**。結果間違うのはしょうがないが**間違っているのがわかっているのに目的を履き違えで進むのは絶対ダメ**。**われわれの目的は可能な限り正確にホームページにデータを出すこと**。」

**Why(根本):** 私の常習的な失敗パターン = 「**表示を通す/フォルダを作る**」を目的化し、 正確さを犠牲にする。具体例(全部このセッションで叱られた):
- 著者role を一律 `writer_artist` で埋めた(表示を通すため) → [[feedback_never_default_author_role]]
- slug を pykakasi で漢字推測(kana読みが手元に在るのに) → 君→`kunnomeiha` → [[acquire_all_obtainable_info]]
- 非漫画(ゲゲゲ女房エッセイ)を名前一致でページ化・巻補完 → [[ndl_discovery_nonmanga_false_positives]]
これらは全部「**間違いと分かる/分かり得るのに、目的(=正確なHP)を履き違えて、埋めること自体を目的化**」した。

**How to apply(鉄則):**
1. ★**目的は「正確さ」**。「ページが出る/フィールドが埋まる/エラーが消える」は目的でない、 手段。表示要件(Zod必須等)を**ダミーで満たすのは禁止**。
2. ★**適当に埋めない**: slug=必ず読み(kana)から / 著者role=必ず実ソース(creators_roled)から / 巻=同一作確認してから / 漫画性=中身(caption/NDL)確認してから。取れる権威データを使わず推測で埋めるのは「適当」。
3. ★**間違いと分かって進まない**: 結果的な誤り(知り得なかった)は許容。但し「これ怪しい/確認してない」と**気づいた時点で、埋めずに止めて確認 or flagして報告**する。怪しさを飲み込んで前進しない。
4. ★**正確化できないなら、載せずに保留 or ユーザに確認**。不確実なものを「とりあえず出す」のが最悪。[[feedback_complete_data_before_ship]] と一体。
5. NDL登録(discovery→ページ化)自体は必要で価値ある。やめるのでなく、**精度を上げて**やる(読み・著者・巻・漫画性の各検証を経て)。

★この原則は個別memoryの上位。判断に迷ったら「これは正確か? 表示優先で履き違えてないか?」を必ず自問する。
