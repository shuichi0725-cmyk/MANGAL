**なぜ先頭に来ないか(3分類・全件どれか)**: 初刊が古い 56 / pin規則 19 / 書影の充足 18。
= **並び順は書影の充足と発売日だけで決まっており、巻説明の有無を一切見ていない**。

**ユーザ方針(2026-09-17)**:
- 通常版で巻説明が作れず文庫で作った場合は **文庫に出す**。 **巻割りの変換は捏造なのでしない**。
- **巻数が通常と文庫で同じなら通常に出す**。

**仕分け**: 冊数が同じ **37頁(75巻)** = 1:1対応なので通常側に出せる /
冊数違い **56頁(184巻)** = そのまま。
★37頁のうち21頁は「先頭が文庫で説明が通常に在る」逆パターン = 移すのでなく**通常版を先頭に出す**方が筋。

**未決**: 実現手段が2つあり裁定待ち。
A案 = 通常版ISBNをキーに seed へ同文を追記(データ複製 → 片方だけ直すと食い違う)
B案 = 並び順に「巻説明がある版を優先」を足す(データ複製なし。 ただし2026-09-04の
「書影が揃った版を上に」裁定と競合するのでどちらが勝つかの裁定が要る)。 私の推奨はB案。
