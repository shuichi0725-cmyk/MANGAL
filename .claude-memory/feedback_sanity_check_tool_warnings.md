★見抜く機会は**3回**あった: ①「SemrushBotが/browseにPUTして204」というありえない行 ②「PUT204」と

特に③ = **自分の新しい観測が既存の独立した観測と矛盾したら、報告する前に必ず検算する**。
矛盾は「重大発見」ではなく「まず自分の測り方を疑う合図」。
今回の検算の型 = 別系統の数字と突き合わせる(UNK除外の合計 30,758 ≒ Worker invocations 30,254)。

## ★再発(2026-09-24)= ツールの定型文を「結論」として報告した

NDL照会1件目の 429 で出た定型文「★NDL429 → 即中断。回復するので慌てず休ませる(1時間単位)」をそのまま受け、
「NDL側でこのIPが制限されている」と報告した。その後の再試行で**5件通って6件目で429**になったのに、まだ「制限中」と言った。
ユーザ指摘「規制されてるなら6件叩けたのが矛盾してない?」で是正(単発429≠規制= [[ndl_access_rate_method]])。
★型: **定型文はツール作者の一般論**であって今回の観測の解釈ではない。「規制」「遮断」のような状態の断定は、
**観測(何件目で・何回連続で)を並べてから**言う。1点の観測で状態を断定しない。
