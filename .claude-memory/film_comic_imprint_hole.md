★**掲載対象外のフィルムコミックが本番に45頁出ていた**(2026-07-26 ユーザ発見「美少女戦士セーラームーンSはフィルムコミック」)。

## 穴の型
既存の網は2つしか見ていなかった:
 ① **title の prefix**「アニメコミック/テレビアニメ版/劇場版」 ② **edition_type=anime**
★通り抜けたのは **title=素の作品名 / type=standard / imprint だけがアニメ物** の版
(もののけ姫・千と千尋・となりのトトロ・AKIRAアニメコミックス・十二国記・ガンダムSEED 等)。

## 恒久修正
`_promote-bulk-v2.py` の `DROP_IMPRINT_PATTERNS` に **7語**を追加:
`アニメコミック / アニメ絵本 / テレビ絵本 / アニメアルバム / メディアブックス / アニメKC / 絵コンテ全集`
種2全走査で該当imprintは**全てアニメtie-in**、正規漫画レーベルの巻き添えは0を確認済み。

## ★ISBN単位の除外は効かない(実証)
AKIRAのアニメ版6 ISBNを `volume-exclude.yml` で除いたら、**2003年の別刷り5 ISBN**が出てきて再表示。
アニメコミックスは版を替えて何度も出るので**レーベル単位でしか塞げない**。

## 一括不可のレーベル(per-case必須)
★**アニメージュコミックススペシャル は混在**。 ジブリ劇場作品はフィルムコミックだが、
**銀河英雄伝説35巻(道原かつみ)/夢幻紳士 怪奇編/闇狩り師/あさりよしとお短編集/中空知防衛軍**は本物の漫画。
→ ジブリ12作は `non-manga-drop.yml` に series_key で個別登録した。
