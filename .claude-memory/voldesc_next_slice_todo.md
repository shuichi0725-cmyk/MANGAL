## ★今回直した穴(2026-07-31)

`_voldesc-material.py` は材料なし台帳を**auto実行時しか書かなかった**ため、
巻数順ランキングが**同じ作を永久に先頭へ出し続けた**(ゴルゴ13が何度も1位)。
→ `--local-only` なら slug 指定時も記録するよう修正済み(commit 済)。

## ★材料の質で3類型ある(判定してから書く)

1. **巻ごとのあらすじ有** = そのまま書ける(江戸前の旬 vol117以降 等)。
2. **収録話リストのみ**(シリーズ共通の惹句+目次) = 収録話・料理名から巻内容として書ける
   (クッキングパパの大半)。★ただし **「A」「B」「C」の羅列をcaption順のまま写すと
   50字連続一致ゲートでrejectされる**(実測21件)→ **、区切り+順序入替+一部言い換え**で回避。
3. **目次の枠だけ/中身なし** = 書けない → 台帳行き(ミナミの帝王142巻=「銭の一〜銭の九」のみ、
   クッキングパパ11巻=惹句のみ、江戸前の旬 vol81=シリーズ紹介のみ)。
