## 2026-09-30 羅針盤の裁定(実装済・テスト環境のみ・app/lab/magic-shelf)
- 広げ方 = **星屑が基本・「年表」ボタンだけ**(扇・同心円は選べない=計算は残置)。 同じ年の糸は年表ボタン自体を出さない。
- **ジャンル**(橙 #ff9f5a) = 重なり(共通÷和集合)**75%→足りなければ60%→50%**(ラベル よく似た/似た/やや似たジャンル)。 周りの本にも広げるにも出る。 上の糸チップ5つ(案D=「旅を保存」は旅路の段の右端)。
- **くじ** = 候補全体から重み(1+近さ)^3(近い本が出やすい・**人気は使わない**=「下と決めつけない」ユーザ裁定)。 広げるたび引き直し+「↻ 引き直す」(直前24冊を外す)+旅で辿った本を外す。 周りの本もくじ・**一歩ごとの seed** で同じ中央なら同じ顔ぶれ。
- **周り10枠**(36°おき・種類ごと2枠: 北寄り作者/北東ジャンル/東〜南東雑誌/南年/西要素)。 空き枠は ジャンル→要素→年→雑誌→作者 の3冊目で埋める。 来た道は1枠使う(11冊だと360pxで重なる)。 楕円 rx≤142・ry≤185・中心 CY=(H-44)/2(5画面×全方向で重なり0・はみ出し0を実測)。
- シート: 書影を押すと大きく(楽天は ?_ex=600x600)・**詳細は書影の下**(作品頁へ・テスト環境では本番 mangal-db.com の頁)・キャッチは選択なし3行/選択中5行。 何もない所を押すと選択解除。
- 詳細→OSの戻る = sessionStorage `mangal:compass:resume:v1` に path/prev/backAng/sel/exp/表示中24冊(1時間・1回)で復元。
- 本棚の呼び名は「**本棚**」に統一(書庫・マイ本棚は廃止)。 作品頁の「同ジャンル検索 →」右に羅針盤マーク(テストのみ)。 作品頁の題名の背景に網点の帯(案1・テストのみ)。
