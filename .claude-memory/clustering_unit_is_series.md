★**作品(ページ)の単位 = シリーズ(具体的な題の巻ライン)**。複数seriesを1ページに統合してよいのは **「同一シリーズ題 + 巻番号が連続/整合」** の時**だけ**。

**統合の軸にしてはいけない物(=これらが同じでも統合しない):**
- **同じ題材/IP** … ARIEL は 小説20巻・コミック14巻・アウターストーリー・ドラマCD・画集 が全部別作品。同IPは横の繋がりにならない。
- **同じ出版社** … 同社が同IPで複数シリーズを出す(朝日ソノラマ=ARIEL COMIC と エリアルアウターストーリーは別)。
- **著者** … アンソロジーで巻ごとに回転し、ベルセルクで代替わりする。**著者をクラスタキーにしたのが分裂の根本原因**([[series_fragmentation_rootcause]])。

**唯一の統合理由 = 同一シリーズ題 + 巻番号連続:**
- ✅ ベルセルク vol1-42(三浦建太郎)+ vol43続編(森恒二/スタジオ我画)= 同題「ベルセルク」・巻番号連続 → **統合**(作者代替わりは無関係。MADB唯一級の作者死後続編)。
- ✅ ARIEL: `Ariel` no1 + `ARIEL COMIC` no2-8 + NDL補完9-14 = 題の表記揺れを正規化して **14巻1作品に統合**。
- ❌ ARIEL COMIC(14)と エリアルアウターストーリー(1)= 別題・各自の巻番号 → **別作品(14と1で分ける)**。同社・同IP・同原作でも統合しない。

**Why:** ★私(Claude)は「同IP/似た題/同出版社だから一つにまとめなきゃ」と**できない・不要な統合を背負い込む**癖がある(ユーザ指摘: 「出来ないことをやろうとするから出来ない」)。デフォルトは**分離**で、同名の別作品が並ぶのは許容(既存の同名suffix `-2` で別ページ化される)。アンソロジーを「まとめる」必要は無い=横の繋がりが題材以外に無い。[[feedback_efficiency_first]] と同根。

**How to apply:**
- 統合判定 = **(正規化した同一シリーズ題) AND (巻番号が連続/整合)**。それ以外は分離。
- アンソロジー: 各製品(題+出版社の1本)を独立作品として置く。巻ごとに著者が変わっても**その本の寄稿者の和集合=著者**。別社の同名は別作品。
- ベルセルク型(作者死後/代替わり続編)だけ、同題+巻連続で例外的に繋ぐ。
- ★「同IPだから」「同社だから」で統合しようとしない。題材の一致は統合根拠ではない。
- ★**有名原作者の同名漫画を別の漫画家が描いていたら=別作品**(ユーザ再確認2026-06-20)。例: 八つ墓村(つのだじろう版/影丸穣也版)・銀河鉄道の夜(古城武司版/ますむらひろし版)・gift・joker 等は**各作画者ごとに別ページ**。原作共通でも統合しない・dedupしない。混入ISBNはde-interleaveで正しい版へ戻すだけ。
- ★**歴史系(学習漫画)はアンソロジーに近い**(ユーザ再確認2026-06-20)。巻ごと別作画で多著者。**同じシリーズかどうかだけが論点**で、**歴史系を横断でまとめる必要は無い**。別シリーズ(別出版社/別監修ライン)は別作品として分離、無理に統合しない。
- 但し書き: 個々のアンソロジーの keep/drop や細部は別途個別判断が要る(ユーザ確認済の原則は上記まで)。
